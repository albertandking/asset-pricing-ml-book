(glossary)=
# 术语对照：学术与业界

同一个词，在学术论文、国内量化业界和本书中可能含义不同。“因子”在论文里通常是一条收益序列，在量化私募的因子库里却往往是每只股票每期的一个数值；“超额收益”在论文里是减去无风险利率，在公募的业绩报告里却常常是减去基准指数。读文献或与业界交流时，需要先确认对方的口径，再讨论结论。本页逐个对照这些术语，随各章写作逐步补充。业界口径以国内量化私募、公募量化与卖方金工的通行用法为准，各机构的具体定义不一。

每个术语按同一个格式介绍：先用一两句白话说明，然后依次给出**学术含义**、**业界常见含义**、**本书用法**与**常见混淆**，必要时配一个小例子。本页的记号与[记号表](notation.md)一致；概念的数值例子见第 0 章[基本概念速览](#sec-ch0-concepts)，因子、特征、载荷三者的关系见[该节的对应小节](#sec-ch0-fcl)。页末有一张[总表](#glossary-summary)。

(glossary-factor)=
## 因子（factor）

**白话。** 学术界说的因子，是许多股票共同面对的一条收益序列；业界说的因子，多数时候是给每只股票打的一个分数。

**学术含义。** 因子是随时间变化、对所有资产共同的变量，资产收益通过载荷对它产生反应。最常见的是可交易因子，即某个组合的超额收益，例如市场因子与按市值、账面市值比排序构造的规模、价值因子 [@fama1993common]，以及中国市场的 CH3 [@liu2019size]；也可以是不可交易的宏观变量，例如消费增长、通胀或工业产出的意外变化；还可以是从收益中提取的统计因子（主成分）。无论哪一种，因子每期只有一个值，不带股票下标。

**业界常见含义。** 国内量化业界说的“因子”，多数时候指选股信号：每期给每只股票算一个数值，据以排序选股，例如“动量因子”“换手率因子”“分析师预期因子”。“因子库”是大量这类信号的集合，“因子挖掘”是用人工经验、遗传规划或机器学习批量构造新信号。业界也区分“alpha 因子”（用来预测收益的信号）与“风险因子”（风险模型中的风格因子，见[风险模型](#glossary-risk-model)），后者更接近学术含义。

**本书用法。** 因子指收益序列 $\mathbf f_t \in \Real^K$，分量为 $f_{k,t}$，不带股票下标；本书的模拟因子都是超额收益（[记号表](notation.md)，第 0 章 0.2 节“因子”）。业界意义上的“因子”，本书称为[特征或信号](#glossary-characteristic)，记作 $\mathbf z_{i,t-1} \in \Real^L$。

**常见混淆。** 听到“换手率因子”，要先问是指每只股票的换手率（特征），还是按换手率排序构造的“低减高”组合收益（因子）。前者是 $N$ 只股票的一列数，后者是一条时间序列。说“因子有效”时，业界通常指信号能预测下期收益（IC 显著，见 [IC](#glossary-ic)）；学术上说“因子被定价”，指它的风险溢价不为 0，二者不是一回事。多因子时，“被定价”还有两种不同的标准：$\lambda_k \neq 0$（因子本身有平均补偿）与 SDF 系数 $b_k \neq 0$（控制其他因子之后，它仍有助于解释期望收益）；因子相关时二者可以不同（见第 3、4 章）。

(glossary-characteristic)=
## 特征、信号、异象（characteristic, signal, anomaly）

**白话。** 特征是期初就能观察到的股票属性；用它来预测收益时常叫信号；如果按它排序得到的收益差不能被现有模型解释，就称为异象。

**学术含义。** 特征（characteristic）是公司或股票层面的可观测变量，例如市值、账面市值比、过去 12 个月的累计收益、换手率，通常在每期横截面上标准化或取排序。信号（signal）一词更常见于预测与组合构造的语境，强调“据以做决策的信息”。异象（anomaly）是一个更强的结论：按某个特征排序的多空组合有显著的平均收益，而且这一收益不能被某个基准定价模型（如 CAPM、Fama–French 三因子）的载荷解释，即相对于该模型的 [α](#glossary-alpha) 显著不为 0。异象总是相对于某个模型而言的。

**业界常见含义。** 业界通常把这三者都叫“因子”或“alpha 因子”，较少使用“特征”“异象”两个词。“因子值”就是特征在某期的取值，“因子暴露”在不同场合可能指特征值本身（见[载荷](#glossary-loading)）。业界说一个因子“失效”，通常指它近期的预测力或多空收益明显下降。

**本书用法。** 特征记作 $\mathbf z_{i,t-1} \in \Real^L$，分量 $z_{j,i,t-1}$，在第 $t-1$ 期末已知，用来解释第 $t$ 期的收益；带常数项的版本为 $\tilde{\mathbf z}_{i,t-1} = (1, \mathbf z_{i,t-1}')' \in \Real^{L+1}$（第 0 章 0.2 节“特征”）。“信号”在本书中与特征同义，侧重预测用途；“异象”只在明确了基准模型时使用。

**常见混淆。** 一个特征能预测收益，不等于它是异象，更不等于存在错误定价：在第 0 章的模拟市场中 $\bv\theta = \mathbf 0$，没有任何错误定价，$z_1$ 却能预测收益，因为它决定了对因子 2 的载荷（第 0 章“常见误区”的误区四）。只有在控制了基准模型的载荷之后预测力仍然存在，才谈得上异象。

(glossary-loading)=
## 载荷、暴露、β（loading, exposure）

**白话。** 载荷是股票对某个因子的敏感度：因子收益每高 1 个百分点，股票收益平均高多少个百分点。

**学术含义。** 载荷是收益对因子的回归斜率，或者模型中乘在因子前面的系数。传统做法用时间序列回归给每只股票估计一个常数载荷；条件模型中载荷随时间变化，常设为特征的函数，例如 IPCA 中的 $\bv\beta_{i,t} = \bv\Gamma'\tilde{\mathbf z}_{i,t-1}$ [@kelly2019characteristics]。“暴露”（exposure）在学术文献中基本是载荷的同义词。

**业界常见含义。** 在 Barra 类风险模型中，“因子暴露”直接取标准化后的特征值（风格因子），或者行业归属的 0/1 哑变量（行业因子），不是从时间序列回归估计出来的。风格暴露通常由多个描述变量（descriptor）合成，部分风格还对其他风格做了正交化；标准化时以市值加权均值为 0，所以暴露是相对于市值加权的市场而言的。组合的因子暴露是成分股暴露按权重的加权和，例如“组合的市值暴露为 $-0.3$”表示组合比市值加权的市场整体偏向小盘，“控制风格暴露”就是把这些加权和限制在某个范围内。

**本书用法。** 载荷记作 $\bv\beta_{i,t} \in \Real^K$，分量 $\beta_{k,i,t}$；本书模型中 $\bv\beta_{i,t} = \bv\Gamma'\tilde{\mathbf z}_{i,t-1}$，$\bv\Gamma \in \Real^{(L+1)\times K}$。$N$ 只股票的载荷按行堆叠为 $\mathbf B_t \in \Real^{N\times K}$（[记号表](notation.md)，第 0 章 0.2 节“载荷”）。

**常见混淆。** 在 Barra 模型内部，暴露按定义就是对 Barra 风格因子的载荷，二者同号。容易混淆的是 Barra 暴露与学术因子的载荷：一只小盘股的 Barra 市值暴露为负（对数市值低于平均），它对学术规模因子 SMB 的载荷却通常为正。这个符号差别只是因为 SMB 的方向是“小减大”，而 Barra 规模因子的方向随市值增大，并不是暴露与载荷的本质区别。真正的区别在于三点：尺度不同（第 0 章模拟器中载荷是 $0.5\, z_1$，而 Barra 式的暴露就是特征本身）；学术载荷需要估计，暴露可以直接观察；“特征决定载荷”只是一个模型假设。只有在这一假设成立、且映射为单位阵的特例下，两者才一致，见第 0 章[因子、特征、载荷的关系](#sec-ch0-fcl)。

(glossary-factor-return)=
## 因子收益（factor return）

**白话。** 因子收益就是因子每期的取值；问题在于，不同的人说的“因子”不同，算出来的“因子收益”也不同。

**学术含义。** 可交易因子的收益，就是构造它的组合（通常是多空组合）每期的超额收益，例如 SMB 在某个月的收益。不可交易因子没有“收益”，只有每期的取值。

**业界常见含义。** 至少有三种口径。第一，Barra 类风险模型中，因子收益是每期横截面回归 $\mathbf r_t$ 对暴露矩阵的回归系数；它等于一个“纯因子组合”的收益，这个组合对该因子的暴露为 1、对其他因子的暴露为 0。第二，评价一个信号时，因子收益常指按信号排序的多空组合（例如最高 10% 减最低 10%）的收益。第三，指按信号分组（例如分 5 组或 10 组）后各组的收益，用来看“单调性”。

**本书用法。** 因子收益指 $\mathbf f_t$ 本身。横截面回归得到的系数，本书记作 $\hat{\mathbf g}_t$，在第 0 章的模型中它估计的是 $\bv\Gamma\mathbf f_t + (0, \bv\theta')'$，而不是 $\mathbf f_t$（第 0 章[因子、特征、载荷的关系](#sec-ch0-fcl)）。

**常见混淆。** 三种口径的数值不能直接比较。例如某个月小盘股跑赢大盘股，SMB 为正；Barra 的规模风格以标准化对数市值（市值加权均值为 0）为暴露，回归系数衡量的是“市值每高一个标准差，收益高多少”，这个月通常为负。多空组合收益的大小还取决于分组的分位点、加权方式与股票池。第 0 章的模拟中，对 $z_1$ 的回归系数约为 $0.5 f_{2,t}$：系数的尺度取决于特征到载荷的映射。

(glossary-risk-premium)=
## 风险溢价（risk premium）

**白话。** 风险溢价有两个意思：承担一单位因子风险得到的平均补偿（单价），以及一项资产因为承担风险而比无风险利率多得的期望收益（总价）。

**学术含义。** 因子风险溢价 $\bv\lambda$ 是每单位载荷的价格，$\E[r_i] = \bv\beta_i'\bv\lambda$；因子是超额收益且被正确定价时，$\bv\lambda = \E[\mathbf f_t]$。资产的风险溢价则指它的期望超额收益 $\E[r_i]$，在 $\alpha_i = 0$ 时即“单价乘以数量”之和 $\bv\beta_i'\bv\lambda$。两种说法都很常见，需要从上下文判断。

**业界常见含义。** 卖方策略研究中最常见的是“股权风险溢价”（ERP），通常用指数的盈利收益率（市盈率的倒数）减去长期国债收益率来度量，作为“股债性价比”的指标。这是一个估值指标，与学术上的期望超额收益相关，但不是同一个量。量化业界也会说某个风格因子“有风险溢价”，意思是它长期有正的平均收益。

**本书用法。** $\bv\lambda \in \Real^K$ 专指因子风险溢价（每单位载荷的价格）；资产的期望超额收益写作 $\E[r_{i,t}]$ 或条件版本 $\E_{t-1}[r_{i,t}] = \alpha_{i,t} + \bv\beta_{i,t}'\bv\lambda$，不叫 $\bv\lambda$（第 0 章 0.2 节“风险溢价”）。

**常见混淆。** 例如在第 0 章的例子中，三个因子的风险溢价为 $\bv\lambda = (0.6\%, 0.3\%, 0.4\%)'$，载荷为 $(1.5, 0.2, 0.1)'$ 的券商股的期望超额收益为 1.00%。说“券商股的风险溢价是 1%”与说“市场因子的风险溢价是 0.6%”用的是同一个词的两个含义。不可交易因子的 $\bv\lambda$ 一般不等于因子的均值。

(glossary-alpha)=
## alpha（α）

**白话。** 学术上的 α 是一个模型解释不了的平均收益；业界的 α 往往就是跑赢基准的部分。

**学术含义。** α 是相对于某个定价模型的定价误差，即时间序列回归 $r_{i,t} = a_i + \bv\beta_i'\mathbf f_t + u_{i,t}$ 的截距 $a_i$（因子为超额收益时）。Jensen 用 CAPM 回归的截距评价基金业绩，这一截距称为 Jensen's alpha [@jensen1968performance]。α 总是相对于某一个选定的模型而言：换一个模型，α 就变了。

**业界常见含义。** 至少有三种用法。第一，相对基准（如沪深 300、中证 500）的超额收益，例如“今年 alpha 10%”；第二，一类策略，“alpha 策略”通常指买入股票组合、同时卖空股指期货对冲市场风险的市场中性策略（见[多空组合与对冲](#glossary-long-short)）；第三，对个股收益的预测值或信号，“alpha 模型”“alpha 因子”即此义。Grinold 与 Kahn 把 alpha 定义为对残差收益（剔除基准相关部分之后）的预测 [@grinold2000active]，与第三种用法一致。

**本书用法。** $\alpha_{i,t}$ 是定价误差，本书模型中 $\alpha_{i,t} = \bv\theta'\mathbf z_{i,t-1}$，$\bv\theta \in \Real^L$；时间序列回归的截距记作 $a_i$（第 0 章 0.2 节“定价误差”，[定价误差](#glossary-pricing-error)）。

**常见混淆。** 相对基准的超额收益里包含了 β 偏离。例子：基准指数上涨 10%，一个对基准 β 为 1.2、Jensen α 为 0 的组合上涨约 12%（暂不考虑无风险利率），业界口径的“超额收益”约为 2%，但这 2% 全部来自更高的 β，学术口径的 α 为 0。反过来，一个 β 为 0.8 的组合在下跌市中“跑赢基准”，也未必有 α。

(glossary-beta)=
## beta（β）

**白话。** β 就是载荷，最常指对市场的载荷：市场涨 1%，这只股票平均涨多少。

**学术含义。** 单因子（CAPM）中 β 是对市场组合的载荷，$\beta_i = \Cov(r_i, f_{\text{mkt}})/\Var(f_{\text{mkt}})$；多因子时 β 泛指载荷向量 $\bv\beta_i$。

**业界常见含义。** “beta 收益”指承担市场或基准风险就能得到的收益，即指数本身的涨跌，与需要选股能力的“alpha 收益”相对。“smart beta”指按规则（如低波动、红利、价值、等权）而不是按市值加权构造的指数或指数基金，学术上更接近[因子投资](#glossary-factor-investing)：系统地获取某些风格因子的收益。“高 beta 股票”“beta 弹性”则与学术用法一致。

**本书用法。** β 即[载荷](#glossary-loading) $\bv\beta_{i,t} \in \Real^K$；单因子时可记作标量 $\beta_i$。

**常见混淆。** 在包含相应因子（如价值、低波动）的模型中，smart beta 产品的收益大多表现为对这些因子的载荷，而不是 α；相对 CAPM 或 Fama–French 三因子这类不含低波动因子的模型，低波动组合本身就常表现出正的 α。但业界宣传中，相对沪深 300 的超额常被称为 alpha。二者口径不同，前者问“模型能否解释”，后者问“是否跑赢某个指数”。

(glossary-factor-investing)=
## 因子投资（factor investing）

**白话。** 学术上的因子投资，是长期、系统地持有少数几个被反复证实有正平均收益的因子组合，以获取风险溢价；国内量化业界说的因子投资，多数时候指“多因子选股”：用大量信号给股票打分，再通过组合优化追求跑赢基准。

**学术含义。** 因子投资源于因子模型与异象文献：如果价值、动量、规模、低波动、盈利质量等因子长期有正的风险溢价，投资者就可以按规则持有相应的多空组合，或在市值加权组合的基础上向这些因子倾斜（tilt）。Ang 把资产配置进一步理解为对底层因子风险的配置 [@ang2014asset]。学术研究关心的问题是：溢价为什么存在（风险补偿还是错误定价，第 8 章）；发表之后是否衰减 [@mclean2016does]；扣除交易成本之后是否还在（第 26 章）；少数几个因子能否概括大量异象（第 16、18 章）。因此，学术意义上的因子投资通常因子数量少、换手率低、持有期长，并强调每个因子的经济解释。

**业界常见含义。** 海外资产管理行业所说的 factor investing 与学术含义接近，常见产品是按规则构造的 smart beta 或风格指数基金（见 [beta](#glossary-beta)），以及持有多个风格多空组合的风格溢价产品。国内量化业界说的“因子投资”“多因子策略”，多数时候指 alpha 多因子选股：从因子库中选出大量信号（量价、基本面、分析师预期、另类数据等），用线性加权或机器学习合成一个打分，再在风险模型的约束下做组合优化，控制行业与风格暴露，追求相对基准的超额收益（指数增强）或市场中性收益。这类策略往往使用成百上千个信号，量价类信号占比高，换手率高，评价时更看重预测力（[IC](#glossary-ic)）、超额收益、回撤与容量，而不是每个信号的经济解释。业界还有“风格轮动”或“风格择时”，即根据宏观或市场状态调整对风格因子的暴露，学术上称为因子择时，其可行性在文献中仍有争议。以上是通行用法，各机构的具体定义与流程不一。

**本书用法。** 本书中的“因子投资”取学术含义：系统地持有因子组合以获取风险溢价。业界意义上的多因子选股，本书称为“多信号选股”或“基于特征的收益预测”，它正是第四部分收益预测（第 22 章）与可实施性（第 26 章）研究的对象。

**常见混淆。** 第一，同一个“价值因子”在两种语境下的角色可能相反。在学术因子投资中，价值多空组合本身就是收益来源，要长期持有；在国内多因子选股中，价值可能只是打分中的一项信号，同时又作为风险模型中的风格暴露，被约束在接近基准的水平。第二，“有效”的标准不同：学术上看长期平均收益、风险溢价 $\bv\lambda$ 与相对于定价模型的 $\alpha$；业界看 IC、超额收益与回撤。第三，A 股卖空受限，学术多空组合的空头一侧难以实现，国内的因子投资更多以只做多的指数增强形式出现（见[多空组合与对冲](#glossary-long-short)）。

(glossary-excess-return)=
## 超额收益（excess return）

**白话。** 学术上的超额收益是减去无风险利率；业界的超额收益通常是减去基准指数。

**学术含义。** 超额收益 $R^e_{i,t} = R_{i,t} - R^f_{t-1}$，即零成本头寸（借入无风险资金买入资产）的收益。多空组合的收益本身就是超额收益。

**业界常见含义。** 常指相对基准指数（如沪深 300、中证 500、中证 1000）的超额，即“相对收益”，指数增强产品就以它为考核目标。与之相对，“绝对收益”指不以指数为参照、追求正收益的产品（常见于私募）。超额的计算方式也不统一：可以是收益率之差，也可以是净值之比（几何超额）。

**本书用法。** 超额收益一律指减去无风险利率，面板记号为 $r_{i,t}$（即 $R^e_{i,t}$，[记号表](notation.md)）。相对基准的收益差，本书称为“相对收益”或“相对基准的超额收益”，并注明基准。

**常见混淆。** 例子：某月沪深 300 上涨 2%，无风险利率为 0.2%，某指数增强产品上涨 3%。学术口径的超额收益为 $3\% - 0.2\% = 2.8\%$，业界口径的超额收益为 $3\% - 2\% = 1\%$。读产品报告中的“超额”时，先看减去的是什么。

(glossary-pricing-error)=
## 定价误差、异常收益（pricing error, abnormal return）

**白话。** 定价误差是模型解释不了的期望收益；异常收益是某个事件前后，实际收益超出“正常”收益的部分。

**学术含义。** 定价误差是相对于定价模型的 $\alpha_i = \E[r_i] - \bv\beta_i'\bv\lambda$，是一个期望值，即 [alpha](#glossary-alpha) 的学术含义。异常收益（abnormal return，AR）来自事件研究：先用事件之前的一段数据估计“正常收益”模型（例如市场模型 $R_{i,t} = a_i + \beta_i R_{\text{mkt},t} + u_{i,t}$，$R_{\text{mkt},t}$ 为市场指数收益），再计算事件窗口内的实际收益减去模型预测值，并在窗口内累加得到累计异常收益（CAR）。异常收益是逐期的已实现值，不是期望。

**业界常见含义。** 业界较少用“定价误差”一词。事件驱动策略（如业绩预告、指数成分调整、股东增持）中会用到“超额收益”“异常收益”，基准多为市场指数或行业指数，即“收益减去基准”。

**本书用法。** 定价误差记作 $\alpha_{i,t}$（第 0 章 0.2 节“定价误差”）；异常收益在用到事件研究的章节另行定义。

**常见混淆。** 定价误差是期望意义上的量，需要用长样本的平均来估计；异常收益是一次事件中的实现值，噪声很大，只有对大量事件平均之后才有意义。两者都依赖所选的“正常收益”模型。

(glossary-long-short)=
## 多空组合、对冲（long-short, hedged）

**白话。** 多空组合是同时买入一组股票、卖空另一组股票；对冲是用一个空头头寸抵消不想要的风险。

**学术含义。** 学术研究中的多空组合通常假定可以无成本地卖空单只股票：例如买入特征最高的 10%、卖空最低的 10%，两条腿的金额相等，组合期初不花钱，收益就是超额收益。因子（如 SMB、HML）与异象的收益大多按这种方式计算，通常不扣交易成本与融券成本。

**业界常见含义。** A 股融券规模小、成本高，单只股票很难大规模做空。业界常见的做法是买入股票组合、卖空股指期货（沪深 300、中证 500、中证 1000 等股指期货）对冲市场风险，称为“市场中性”或“alpha 策略”，其收益约为股票组合相对期货标的指数的超额，减去对冲成本（包括期货贴水造成的基差损失）。市场中性产品还要为股指期货空头留出保证金，这部分资金不能买入股票，摊薄了收益；期货升水时，卖空期货的基差反而贡献正收益。另一类主流产品是“指数增强”，也是公募量化的主力：只做多，在跟踪某个指数的同时争取超额收益，并限制跟踪误差，满足投资者“既要指数的 β、又要超额收益”的需求。

**本书用法。** 多空组合指学术意义上的零成本组合，权重向量 $\mathbf w_t \in \Real^N$ 满足 $\mathbf w_t'\mathbf 1_N = 0$（第 0 章[因子、特征、载荷的关系](#sec-ch0-fcl)）；可实施性与交易成本在第 26 章讨论。

**常见混淆。** 学术多空收益不等于业界可实现的收益：A 股的空头腿基本无法照做，一个异象的收益若主要来自空头腿，只做多或用期货对冲都拿不到它。评价 A 股的信号时，应当把多头相对基准的超额单独列出。

(glossary-neutralization)=
## 中性化（neutralization）

**白话。** 中性化是把一个信号中能被行业、市值等解释的部分去掉，只留下“与行业、市值无关”的那部分。

**学术含义。** 学术论文较少用“中性化”一词，更常说控制变量、行业调整（industry-adjusted）或特征调整收益（例如按规模、账面市值比与动量匹配基准组合的 DGTW 调整，DGTW 指 Daniel、Grinblatt、Titman 与 Wermers）。最接近的做法是“控制变量”：在 Fama–MacBeth 横截面回归 [@fama1973risk] 中同时放入信号与市值、行业等控制变量，看信号的系数（第 10 章）；或者做双重排序，先按市值分组，再在每个市值组内按信号排序，看信号的收益差。

**业界常见含义。** 每期在横截面上把信号对行业哑变量与对数市值（有时还有其他风格因子）做回归，取残差作为“中性化后的因子值”，再用它计算 IC、分组收益或构造组合。组合层面的“行业中性”“市值中性”则指组合对行业与市值的暴露与基准相同或为 0。

**本书用法。** 本书用“控制变量”与“残差化”的说法，并注明控制了哪些变量。被中性化的信号是特征 $z_{j,i,t-1}$（[记号表](notation.md)）；横截面回归的写法见第 0 章[因子、特征、载荷的关系](#sec-ch0-fcl)。

**常见混淆。** 由 Frisch–Waugh–Lovell 定理，收益对“信号与控制变量”做多元回归时信号的系数，等于收益对“残差化后的信号”做一元回归的系数（附录 A 讨论投影时给出证明）。这一等价有成立条件：两次回归用同一样本；残差化用的就是多元回归中的那一组控制变量，并且其中含常数项或完整的行业哑变量（使残差化后的信号均值为 0）；两步用同一加权方式（例如都用等权 OLS）；残差化之后不再做缩尾或标准化。业界常见的“中性化后再标准化”会按标准差改变系数的尺度，但不改变符号；对残差做 Rank 化，或者一步用 WLS、另一步用等权 OLS，等价就不再成立。IC 也不同：中性化后的信号与原始收益的相关系数是半偏相关系数（part 或 semipartial correlation），不等于偏相关系数，因为收益本身没有被残差化。双重排序是同一思路的非参数版本，但在特征相关或关系非线性时，结果可能与回归控制不同。

(glossary-fm)=
## 横截面回归与 Fama–MacBeth（cross-sectional regression, Fama–MacBeth）

**白话。** 横截面回归是固定一期、沿股票跑的回归，回答“这一期，特征或载荷高的股票多赚了多少”；Fama–MacBeth 是每期各跑一次横截面回归，再对系数求时间平均，用系数的时间序列波动计算标准误。

**学术含义。** 第 $t$ 期的横截面回归把 $N$ 只股票的收益 $\mathbf r_t$ 对股票层面的变量回归，解释变量可以是载荷估计值 $\hat{\bv\beta}_i$，也可以是期初特征 $\tilde{\mathbf z}_{i,t-1}$，得到当期的系数 $\hat{\mathbf g}_t$。Fama–MacBeth 程序 [@fama1973risk] 取 $\bar{\mathbf g} = T^{-1}\sum_t\hat{\mathbf g}_t$ 为点估计，逐分量以 $\hat g_{j,t}$ 的时间序列标准差除以 $\sqrt T$ 为标准误；同期股票之间的相关被压缩进每期的一个系数，因而自动计入。对载荷回归时，$\bar{\bv\lambda}$ 估计风险溢价 $\bv\lambda$；载荷需先由时间序列回归估计（两步法），由此带来的变量误差与 Shanken 修正 [@shanken1992estimation] 见第 10 章。

**业界常见含义。** 第一，Barra 类风险模型中的“因子收益”就是每期横截面回归的系数，解释变量是行业哑变量与标准化的风格暴露（[因子收益](#glossary-factor-return)、[风险模型](#glossary-risk-model)）。第二，卖方金工单因子测试中的“回归法”：每期把下期收益对因子值做横截面回归，通常同时放入行业哑变量与对数市值，即做行业与市值的[中性化](#glossary-neutralization)，得到因子收益序列与每期的 $t$ 值序列，再报告因子收益的均值（及其 $t$ 值）、$t$ 值绝对值的均值、$|t| > 2$ 的期数比例等。第三，[IC](#glossary-ic) 是信号与收益的横截面相关系数，与一元横截面回归的斜率只差一个比例。以上是通行用法，各机构的具体做法（加权方式、是否对因子值排序、控制哪些变量）不一。

**本书用法。** 横截面回归的系数记作 $\hat{\mathbf g}_t$（对特征）或 $\hat{\bv\lambda}_t$（对载荷），Fama–MacBeth 点估计记作 $\bar{\mathbf g}$ 或 $\bar{\bv\lambda}$，标准误按上面的时间序列标准差计算（[记号表](notation.md)）。几种回归的对比与模拟见第 0 章[几种回归](#sec-ch0-regs)。

**常见混淆。**

- 业界“$t$ 值序列”中的每期 $t$ 值，是**单期**横截面回归的 OLS $t$ 值，衡量这一期系数相对于这一期横截面噪声的大小；Fama–MacBeth 的 $t$ 值是系数的时间平均除以它的时间序列标准误，衡量平均补偿是否不为 0。二者不是一回事：一个特征可以在多数期都有很大的 $|t|$、而方向时正时负（第 0 章[几种回归](#sec-ch0-regs)的模拟中，$z_1$ 的每期 $t$ 值大于 2 与小于 $-2$ 的期数都超过 15%），平均补偿是否为正，要看 FM $t$ 值（见该节输出）。“$|t| > 2$ 的比例”同样是单期口径，不能当作显著性检验。
- 把全部股票与期数放在一起做一次混合回归，用同方差标准误时，同期残差的相关被忽略，标准误偏小、$t$ 值偏大；残差中含有同期共同的因子冲击时，偏差可以很大。按时间聚类的标准误见第 12 章。
- 时间序列回归的截距与横截面回归的截距含义不同。前者是每只股票一个，因子为可交易的超额收益时，它是这只股票的定价误差 α；后者是每期一个，是当期解释变量全为 0 的（假想）股票的拟合收益。对载荷回归时，它是载荷为 $\mathbf 0$ 的组合在这一期的拟合收益：若用超额收益回归且模型正确，它的时间平均应为 0；用总收益回归时，它估计零 β 资产的收益率。对特征回归时，它是特征全为 0 的基准股票的拟合收益，时间平均是这只基准股票的期望收益，不必为 0，例如第 0 章模拟中约为 $\mu_1$。无论哪种情形，它都不是某只股票的 α。

(glossary-ic)=
## IC、Rank IC、ICIR

**白话。** IC 衡量一个信号每期把股票排得准不准：期初的信号值与本期收益在横截面上的相关系数。

**学术含义。** 学术论文较少直接报告 IC，与之最接近的是 Fama–MacBeth 回归 [@fama1973risk]：每期把收益对信号做横截面回归，看斜率的时间平均与它的 $t$ 值（见[横截面回归与 Fama–MacBeth](#glossary-fm)）。

**业界常见含义。** 第 $t$ 期的 IC 是信号 $z_{i,t-1}$ 与收益 $r_{i,t}$ 在 $N$ 只股票上的 Pearson 相关系数，$\mathrm{IC}_t = \operatorname{corr}_i(z_{i,t-1}, r_{i,t})$；Rank IC 是二者排序之间的相关系数（Spearman 相关系数），对极端值不敏感，业界更常用。ICIR 是 IC 时间序列的均值除以标准差，衡量预测力的稳定性；有的机构还会乘以 $\sqrt{12}$ 年化（月度数据时），口径不一。Grinold 与 Kahn 的“主动管理基本定律”把信息比率近似写成 IC 乘以独立下注次数的平方根 [@grinold2000active]，这是 IC 在业界广泛使用的一个原因。

**本书用法。** 本书在需要时使用 IC、Rank IC 与 ICIR，并说明计算口径（相关系数类型、是否中性化、收益的期限、是否做行业或基准调整）。同一期所有股票的收益减去同一个无风险利率，不改变相关系数与斜率，所以 IC 与是否减去无风险利率无关。信号即特征 $z_{j,i,t-1}$（[记号表](notation.md)），逐期横截面回归的系数沿用第 0 章的记号 $\hat{\mathbf g}_t$（[因子、特征、载荷的关系](#sec-ch0-fcl)）。

**常见混淆。** IC 与 Fama–MacBeth 斜率之间有一个精确关系和两个近似关系，各有前提。精确关系：一元横截面回归 $r_{i,t} = g_{0,t} + g_{1,t} z_{i,t-1} + u_{i,t}$（含截距、等权 OLS）的斜率与同一股票样本上的 Pearson IC 满足

```{math}
:enumerated: false
\hat g_{1,t} = \mathrm{IC}_t \cdot \frac{\hat\sigma_{r,t}}{\hat\sigma_{z,t}} ,
```

其中 $\hat\sigma_{r,t}$、$\hat\sigma_{z,t}$ 是第 $t$ 期收益与信号的横截面标准差（标量），二者须用同一自由度（同为除以 $N$ 或同为除以 $N-1$），比值才不受影响。信号已标准化时 $\hat\sigma_{z,t} = 1$，但只在标准化所用的自由度下成立：按除以 $N$ 标准化的信号，按除以 $N-1$ 计算的标准差并不等于 1。第一个近似关系：信号已标准化、且 $\hat\sigma_{r,t}$ 各期变化不大（约为常数 $\hat\sigma_r$）时，斜率的时间平均 $\bar{\hat g}_1 \approx \hat\sigma_r\,\overline{\mathrm{IC}}$。第二个近似关系：在同样的前提下，Fama–MacBeth 的 $t$ 值 $\bar{\hat g}_1 / (\hat\sigma(\hat g_{1,t}) / \sqrt T)$ 约为 $\mathrm{ICIR} \times \sqrt T$，$T$ 为期数；这里的 ICIR 是未年化的“IC 均值除以 IC 标准差”，并且 IC 标准差的自由度与 Fama–MacBeth 中 $\hat\sigma(\hat g_{1,t})$ 的一致，不是上文乘以 $\sqrt{12}$ 的年化口径。横截面离散度随时间变化较大时（例如市场剧烈波动的月份），两者可以相差不少。Rank IC 对应的是“收益排序对信号排序”的回归，与原始收益的回归斜率只有近似关系。IC 高也不等于多空收益高、更不等于有 α：IC 不区分预测力来自载荷还是定价误差。

(glossary-risk-model)=
## 风险模型、Barra 模型（risk model）

**白话。** 风险模型回答的是“这个组合未来波动多大、风险来自哪里”，而不是“哪只股票期望收益高”。

**学术含义。** 学术资产定价较少单独讨论“风险模型”，与之相关的是协方差矩阵的因子结构估计。在本书的模型中，给定期初特征，收益的条件协方差矩阵为 $\mathbf B_t\bv\Sigma_f\mathbf B_t' + \sigma_\varepsilon^2\mathbf I_N$（$N\times K$、$K\times K$、$K\times N$ 相乘再加 $N\times N$，得 $N\times N$）。

**业界常见含义。** Barra（现属 MSCI）类风险模型中，现行的中国模型（如 CNE5、CNE6）以及美国模型 USE4 之后的版本，把股票收益写成“国家因子 + 行业因子 + 风格因子 + 特异收益”（早期版本没有单独的国家因子）；暴露取行业哑变量与标准化的风格特征，因子收益由每期横截面回归估计，再由因子收益的时间序列估计因子协方差矩阵、由残差估计特异风险。用途是预测组合风险与跟踪误差、做风险归因与业绩归因，以及在组合优化中约束风格与行业暴露。国内券商与第三方也有类似的自建风险模型。

**本书用法。** 本书在第 0 章说明 Barra 式横截面回归是“特征决定载荷”且 $\bv\Gamma = \mathbf I_{L+1}$ 的特例（[因子、特征、载荷的关系](#sec-ch0-fcl)）；统计因子与协方差结构见第 23 章，组合构造中的风险约束见第 26 章。

**常见混淆。** 风险模型的风格因子是为解释协方差而选的，不一定有风险溢价；定价模型的因子是为解释期望收益而选的。一个风格因子在风险模型中很重要（解释了大量共同波动），在定价模型中却可能不被定价，反之亦然。

(glossary-factor-model)=
## 因子模型（factor model）

**白话。** 因子模型是“收益 = 载荷 × 因子 + 其余部分”这一类模型的统称，但不同的因子模型想回答的问题不同。

**学术含义。** 至少要区分三类。**定价模型**解释期望收益的横截面差别，核心是 $\E[r_i] = \bv\beta_i'\bv\lambda$ 与 $\alpha_i = 0$ 的检验，例如 CAPM、Fama–French 三因子 [@fama1993common]、CH3 [@liu2019size]。**统计因子模型**用主成分分析等方法从收益的协方差中提取因子，目标是解释共同波动；IPCA 把载荷设为特征的函数，兼顾二者 [@kelly2019characteristics]。**风险模型**（见上一条）以预测协方差为目标。

**业界常见含义。** “多因子模型”在业界常指多因子选股模型：把多个 alpha 信号加权合成一个综合打分，据以选股或作为组合优化的预期收益输入；也常指 Barra 类风险模型。两种用法的目标完全不同。

**本书用法。** 本书的“因子模型”默认指定价模型；指统计因子模型、风险模型或多因子选股模型时，会明确说明。第 0 章的模拟市场同时是一个定价模型（$\bv\theta = \mathbf 0$ 时）与一个协方差结构已知的统计模型。

**常见混淆。** 业界的“多因子选股模型”中的“因子”是信号，模型输出的是预测值；学术的“多因子模型”中的因子是收益序列，模型检验的是定价误差。前者做得好，意味着预测准；后者成立，意味着没有 α。

(glossary-sdf)=
## 随机贴现因子、定价核（stochastic discount factor, pricing kernel）

**白话。** 随机贴现因子给未来的每个状态标一个数：那个状态下一块钱今天值多少，再除以该状态的概率。坏时候的数大，好时候的数小。

**学术含义。** SDF $m_{t+1}$ 满足 $P_t = \E_t[m_{t+1}x_{t+1}]$，是现代资产定价理论的统一框架 [@cochrane2005asset]；线性因子模型等价于 SDF 是因子的线性函数。定价核与 SDF 通常同义。

**业界常见含义。** 国内量化业界很少使用这一概念。业界与估值实务中常说的“折现率”，指把未来现金流折算为现值时用的利率，例如现金流折现模型中的加权平均资本成本，对每项资产是一个数。

**本书用法。** SDF 记作 $m_{t+1}$（面板部分 $m_t$），本书模拟市场中 $m_t = 1 - \mathbf b'(\mathbf f_t - \bv\mu)$，$\mathbf b \in \Real^K$（第 0 章 0.2 节“随机贴现因子”与 0.5 节）。

**常见混淆。** SDF 是一个随状态变化的随机变量，对所有资产相同；折现率是对某一项资产而言的一个数，不同资产不同。二者的联系是：资产的期望收益就是它的折现率，而期望收益由资产收益与 SDF 的协方差决定，$\E[R^e] = -\Cov(m, R^e)/\E[m]$；无风险利率满足 $R^f = 1/\E[m]$。Cochrane 的会长演讲就以“折现率”为题，讨论期望收益为何随时间与资产变化 [@cochrane2011presidential]。

(glossary-risk-free)=
## 无风险利率（risk-free rate）

**白话。** 无风险利率是把钱放在没有违约风险的资产上、期初就已确定的收益。实证中要选一个利率当作它的代理变量。

**学术含义。** 美国股市的实证研究通常用一个月期国库券利率作为月度无风险利率。A 股研究中常见的代理变量有：一年期定期存款利率（折算为月利率）、上海银行间同业拆放利率（Shibor）、短期国债收益率、银行间回购利率等。不同代理变量的水平与波动差别不小，早期利率管制时期尤其如此。CH3 [@liu2019size] 使用的无风险利率口径，需要核对原文（待核实）。

**业界常见含义。** 计算夏普比率等指标时，业界常用一年期定期存款利率、短期国债或货币基金收益率，也有直接取 0 的；评价相对收益产品时，往往根本不减无风险利率，而是减基准指数（见[超额收益](#glossary-excess-return)）。

**本书用法。** 第 $t$ 期适用的无风险总收益记作 $R^f_{t-1}$，在第 $t-1$ 期末已知；模拟器不单独生成无风险利率，归一化 $\E[m_t] = 1$ 相当于 $R^f = 1$（[记号表](notation.md)）。A 股实证中使用的代理变量在第 15 章说明。

**常见混淆。** 月度数据中，无风险利率每月只有零点几个百分点，看似可以忽略，但它会改变时间序列回归的截距与夏普比率；比较不同论文的结果时，应先确认它们用的是哪个代理变量。

(glossary-oos)=
## 样本外（out-of-sample）

**白话。** 样本外就是用估计模型时没有用过的数据来检验模型。

**学术含义。** 预测与机器学习资产定价研究中，样本外检验通常按时间顺序进行：只用第 $t$ 期以前的数据估计模型（滚动窗口或扩展窗口），预测第 $t$ 期，再逐期向前推进；或者把样本按时间分为训练集、验证集与测试集，测试集只在最后用一次 [@gu2020empirical]。样本外 $R^2$ 等指标都以这种划分为前提。

**业界常见含义。** “回测”指在历史数据上模拟一个策略的表现；“模拟盘”指用实时行情模拟交易而不投入资金；“实盘”指真实资金运行。业界常说的“样本外”，有时指回测区间之后的一段历史，有时指上线之后的实盘表现。

**本书用法。** 样本外指估计（包括选模型、调参数、选特征）时完全没有用过的数据，并且只使用每个时点之前可得的信息（第 0 章 0.3 节的时点约定）。

**常见混淆。** 回测不等于样本外：如果信号的构造、参数或股票池是在看过整个回测区间之后才确定的，回测结果就是样本内的。反复修改策略直到回测好看，即使每次都“只用历史数据”，也是在用测试集选模型，会造成过拟合；尝试过的方案越多，回测中最好的结果越可能只是运气（多重检验问题，第 14 章讨论；样本外检验的计量见第 13、19 章）。

(glossary-summary)=
## 总表

| 术语 | 学术含义 | 业界含义 |
|---|---|---|
| [因子](#glossary-factor) | 对所有资产共同的收益序列或宏观变量 | 选股信号；因子库中的一个因子值 |
| [特征、信号、异象](#glossary-characteristic) | 期初可观测的股票属性；不能被基准模型解释的收益差 | 统称“因子”或“alpha 因子” |
| [载荷、暴露、β](#glossary-loading) | 收益对因子的敏感度 | Barra 中标准化的特征值或行业哑变量 |
| [因子收益](#glossary-factor-return) | 因子组合每期的收益 | 横截面回归系数；多空组合或分组收益 |
| [风险溢价](#glossary-risk-premium) | 每单位载荷的价格 $\bv\lambda$；资产的期望超额收益 | 股权风险溢价等估值指标 |
| [alpha](#glossary-alpha) | 相对某个模型的定价误差；Jensen's alpha | 相对基准的超额收益；市场中性策略；收益预测值 |
| [beta](#glossary-beta) | 载荷，尤指市场载荷 | 基准收益；smart beta |
| [因子投资](#glossary-factor-investing) | 长期持有少数有风险溢价的因子组合 | 多信号打分选股，组合优化追求超额 |
| [超额收益](#glossary-excess-return) | 减去无风险利率 | 减去基准指数的相对收益 |
| [定价误差、异常收益](#glossary-pricing-error) | 期望收益中模型解释不了的部分；事件窗口的实际收益减正常收益 | 事件驱动中相对基准的收益 |
| [多空组合、对冲](#glossary-long-short) | 假定可以卖空的零成本组合 | 股指期货对冲的市场中性；只做多的指数增强 |
| [中性化](#glossary-neutralization) | 控制变量回归；双重排序 | 对行业、市值回归取残差 |
| [横截面回归与 Fama–MacBeth](#glossary-fm) | 每期沿股票回归；系数的时间平均及其时间序列标准误 | Barra 因子收益；单因子测试的回归法 |
| [IC、Rank IC、ICIR](#glossary-ic) | 对应横截面回归斜率（精确）及其 $t$ 值（近似） | 信号与下期收益的横截面相关系数及其稳定性 |
| [风险模型](#glossary-risk-model) | 协方差矩阵的因子结构 | Barra 类模型；风险预测与归因 |
| [因子模型](#glossary-factor-model) | 定价模型、统计因子模型、风险模型 | 多因子选股模型；风险模型 |
| [随机贴现因子](#glossary-sdf) | 给各状态定价的随机变量 $m$ | 很少使用；需与折现率区分 |
| [无风险利率](#glossary-risk-free) | 国库券利率；A 股常用存款利率、Shibor、国债收益率 | 计算夏普比率的参照利率 |
| [样本外](#glossary-oos) | 按时间顺序、估计时未用过的数据 | 回测之后的区间；模拟盘与实盘 |

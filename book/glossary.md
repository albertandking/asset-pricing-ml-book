(glossary)=
# 术语对照：学术与业界

同一个词，在学术论文、国内量化业界和本书中可能含义不同。“因子”在论文里通常是一条收益序列，在量化私募的因子库里却往往是每只股票每期的一个数值；“超额收益”在论文里是减去无风险利率，在公募的业绩报告里却常常是减去基准指数。读文献或与业界交流时，需要先确认对方的口径，再讨论结论。本页逐个对照这些术语，随各章写作逐步补充。业界口径以国内量化私募、公募量化与卖方金工的通行用法为准，各机构的具体定义不一。

每个术语按同一个格式介绍：先用一两句白话说明，然后依次给出**学术含义**、**业界常见含义**、**本书用法**与**常见混淆**，必要时配一个小例子。本页的记号与[记号表](notation.md)一致；概念的数值例子见第 0 章[基本概念速览](#sec-ch0-concepts)及其[续页](#sec-ch0-concepts-sdf)，因子、特征、载荷三者的关系见[该节的对应小节](#sec-ch0-fcl)。页末有一张[总表](#glossary-summary)。

- [二、绩效与风险指标](#glossary-group-metrics)（6 条）

(glossary-group-basic)=
## 一、基本概念

(glossary-factor)=
### 因子（factor）

**白话。** 学术界说的因子，是许多股票共同面对的一条收益序列；业界说的因子，多数时候是给每只股票打的一个分数。

**学术含义。** 因子是随时间变化、对所有资产共同的变量，资产收益通过载荷对它产生反应。最常见的是可交易因子，即某个组合的超额收益，例如市场因子与按市值、账面市值比排序构造的规模、价值因子 [@fama1993common]，以及中国市场的 CH3 [@liu2019size]；也可以是不可交易的宏观变量，例如消费增长、通胀或工业产出的意外变化；还可以是从收益中提取的统计因子（主成分）。无论哪一种，因子每期只有一个值，不带股票下标。

**业界常见含义。** 国内量化业界说的“因子”，多数时候指选股信号：每期给每只股票算一个数值，据以排序选股，例如“动量因子”“换手率因子”“分析师预期因子”。“因子库”是大量这类信号的集合，“因子挖掘”是用人工经验、遗传规划或机器学习批量构造新信号。业界也区分“alpha 因子”（用来预测收益的信号）与“风险因子”（风险模型中的风格因子，见[风险模型](#glossary-risk-model)），后者更接近学术含义。

**本书用法。** 因子指收益序列 $\mathbf f_t \in \Real^K$，分量为 $f_{k,t}$，不带股票下标；本书的模拟因子都是超额收益（[记号表](notation.md)，第 0 章 0.2 节“因子”）。业界意义上的“因子”，本书称为[特征或信号](#glossary-characteristic)，记作 $\mathbf z_{i,t-1} \in \Real^L$。

**常见混淆。** 听到“换手率因子”，要先问是指每只股票的换手率（特征），还是按换手率排序构造的“低减高”组合收益（因子）。前者是 $N$ 只股票的一列数，后者是一条时间序列。说“因子有效”时，业界通常指信号能预测下期收益（IC 显著，见 [IC](#glossary-ic)）；学术上说“因子被定价”，指它的风险溢价不为 0，二者不是一回事。多因子时，“被定价”还有两种不同的标准：$\lambda_k \neq 0$（因子本身有平均补偿）与 SDF 系数 $b_k \neq 0$（控制其他因子之后，它仍有助于解释期望收益）；因子相关时二者可以不同（见第 3、4 章）。

(glossary-characteristic)=
### 特征、信号、异象（characteristic, signal, anomaly）

**白话。** 特征是期初就能观察到的股票属性；用它来预测收益时常叫信号；如果按它排序得到的收益差不能被现有模型解释，就称为异象。

**学术含义。** 特征（characteristic）是公司或股票层面的可观测变量，例如市值、账面市值比、过去 12 个月的累计收益、换手率，通常在每期横截面上标准化或取排序。信号（signal）一词更常见于预测与组合构造的语境，强调“据以做决策的信息”。异象（anomaly）是一个更强的结论：按某个特征排序的多空组合有显著的平均收益，而且这一收益不能被某个基准定价模型（如 CAPM、Fama–French 三因子）的载荷解释，即相对于该模型的 [α](#glossary-alpha) 显著不为 0。异象总是相对于某个模型而言的。

**业界常见含义。** 业界通常把这三者都叫“因子”或“alpha 因子”，较少使用“特征”“异象”两个词。“因子值”就是特征在某期的取值，“因子暴露”在不同场合可能指特征值本身（见[载荷](#glossary-loading)）。业界说一个因子“失效”，通常指它近期的预测力或多空收益明显下降。

**本书用法。** 特征记作 $\mathbf z_{i,t-1} \in \Real^L$，分量 $z_{j,i,t-1}$，在第 $t-1$ 期末已知，用来解释第 $t$ 期的收益；带常数项的版本为 $\tilde{\mathbf z}_{i,t-1} = (1, \mathbf z_{i,t-1}')' \in \Real^{L+1}$（第 0 章 0.2 节“特征”）。“信号”在本书中与特征同义，侧重预测用途；“异象”只在明确了基准模型时使用。

**常见混淆。** 一个特征能预测收益，不等于它是异象，更不等于存在错误定价：在第 0 章的模拟市场中 $\bv\theta = \mathbf 0$，没有任何错误定价，$z_1$ 却能预测收益，因为它决定了对因子 2 的载荷（第 0 章“常见误区”的误区四）。只有在控制了基准模型的载荷之后预测力仍然存在，才谈得上异象。

(glossary-loading)=
### 载荷、暴露、β（loading, exposure）

**白话。** 载荷是股票对某个因子的敏感度：因子收益每高 1 个百分点，股票收益平均高多少个百分点。

**学术含义。** 载荷是收益对因子的回归斜率，或者模型中乘在因子前面的系数。传统做法用时间序列回归给每只股票估计一个常数载荷；条件模型中载荷随时间变化，常设为特征的函数，例如 IPCA 中的 $\bv\beta_{i,t} = \bv\Gamma'\tilde{\mathbf z}_{i,t-1}$ [@kelly2019characteristics]。“暴露”（exposure）在学术文献中基本是载荷的同义词。

**业界常见含义。** 在 Barra 类风险模型中，“因子暴露”直接取标准化后的特征值（风格因子），或者行业归属的 0/1 哑变量（行业因子），不是从时间序列回归估计出来的。风格暴露通常由多个描述变量（descriptor）合成，部分风格还对其他风格做了正交化；标准化时以市值加权均值为 0，所以暴露是相对于市值加权的市场而言的。组合的因子暴露是成分股暴露按权重的加权和，例如“组合的市值暴露为 $-0.3$”表示组合比市值加权的市场整体偏向小盘，“控制风格暴露”就是把这些加权和限制在某个范围内。

**本书用法。** 载荷记作 $\bv\beta_{i,t} \in \Real^K$，分量 $\beta_{k,i,t}$；本书模型中 $\bv\beta_{i,t} = \bv\Gamma'\tilde{\mathbf z}_{i,t-1}$，$\bv\Gamma \in \Real^{(L+1)\times K}$。$N$ 只股票的载荷按行堆叠为 $\mathbf B_t \in \Real^{N\times K}$（[记号表](notation.md)，第 0 章 0.2 节“载荷”）。

**常见混淆。** 在 Barra 模型内部，暴露按定义就是对 Barra 风格因子的载荷，二者同号。容易混淆的是 Barra 暴露与学术因子的载荷：一只小盘股的 Barra 市值暴露为负（对数市值低于平均），它对学术规模因子 SMB 的载荷却通常为正。这个符号差别只是因为 SMB 的方向是“小减大”，而 Barra 规模因子的方向随市值增大，并不是暴露与载荷的本质区别。真正的区别在于三点：尺度不同（第 0 章模拟器中载荷是 $0.5\, z_1$，而 Barra 式的暴露就是特征本身）；学术载荷需要估计，暴露可以直接观察；“特征决定载荷”只是一个模型假设。只有在这一假设成立、且映射为单位阵的特例下，两者才一致，见第 0 章[因子、特征、载荷的关系](#sec-ch0-fcl)。

(glossary-factor-return)=
### 因子收益（factor return）

**白话。** 因子收益就是因子每期的取值；问题在于，不同的人说的“因子”不同，算出来的“因子收益”也不同。

**学术含义。** 可交易因子的收益，就是构造它的组合（通常是多空组合）每期的超额收益，例如 SMB 在某个月的收益。不可交易因子没有“收益”，只有每期的取值。

**业界常见含义。** 至少有三种口径。第一，Barra 类风险模型中，因子收益是每期横截面回归 $\mathbf r_t$ 对暴露矩阵的回归系数；它等于一个“纯因子组合”的收益，这个组合对该因子的暴露为 1、对其他因子的暴露为 0。第二，评价一个信号时，因子收益常指按信号排序的多空组合（例如最高 10% 减最低 10%）的收益。第三，指按信号分组（例如分 5 组或 10 组）后各组的收益，用来看“单调性”。

**本书用法。** 因子收益指 $\mathbf f_t$ 本身。横截面回归得到的系数，本书记作 $\hat{\mathbf g}_t$，在第 0 章的模型中它估计的是 $\bv\Gamma\mathbf f_t + (0, \bv\theta')'$，而不是 $\mathbf f_t$（第 0 章[因子、特征、载荷的关系](#sec-ch0-fcl)）。

**常见混淆。** 三种口径的数值不能直接比较。例如某个月小盘股跑赢大盘股，SMB 为正；Barra 的规模风格以标准化对数市值（市值加权均值为 0）为暴露，回归系数衡量的是“市值每高一个标准差，收益高多少”，这个月通常为负。多空组合收益的大小还取决于分组的分位点、加权方式与股票池。第 0 章的模拟中，对 $z_1$ 的回归系数约为 $0.5 f_{2,t}$：系数的尺度取决于特征到载荷的映射。

(glossary-risk-premium)=
### 风险溢价（risk premium）

**白话。** 风险溢价有两个意思：承担一单位因子风险得到的平均补偿（单价），以及一项资产因为承担风险而比无风险利率多得的期望收益（总价）。

**学术含义。** 因子风险溢价 $\bv\lambda$ 是每单位载荷的价格，$\E[r_i] = \bv\beta_i'\bv\lambda$；因子是超额收益且被正确定价时，$\bv\lambda = \E[\mathbf f_t]$。资产的风险溢价则指它的期望超额收益 $\E[r_i]$，在 $\alpha_i = 0$ 时即“单价乘以数量”之和 $\bv\beta_i'\bv\lambda$。两种说法都很常见，需要从上下文判断。

**业界常见含义。** 卖方策略研究中最常见的是“股权风险溢价”（ERP），通常用指数的盈利收益率（市盈率的倒数）减去长期国债收益率来度量，作为“股债性价比”的指标。这是一个估值指标，与学术上的期望超额收益相关，但不是同一个量。量化业界也会说某个风格因子“有风险溢价”，意思是它长期有正的平均收益。

**本书用法。** $\bv\lambda \in \Real^K$ 专指因子风险溢价（每单位载荷的价格）；资产的期望超额收益写作 $\E[r_{i,t}]$ 或条件版本 $\E_{t-1}[r_{i,t}] = \alpha_{i,t} + \bv\beta_{i,t}'\bv\lambda$，不叫 $\bv\lambda$（第 0 章 0.2 节“风险溢价”）。

**常见混淆。** 例如在第 0 章的例子中，三个因子的风险溢价为 $\bv\lambda = (0.6\%, 0.3\%, 0.4\%)'$，载荷为 $(1.5, 0.2, 0.1)'$ 的券商股的期望超额收益为 1.00%。说“券商股的风险溢价是 1%”与说“市场因子的风险溢价是 0.6%”用的是同一个词的两个含义。不可交易因子的 $\bv\lambda$ 一般不等于因子的均值。

(glossary-alpha)=
### alpha（α）

**白话。** 学术上的 α 是一个模型解释不了的平均收益；业界的 α 往往就是跑赢基准的部分。

**学术含义。** α 是相对于某个定价模型的定价误差，即时间序列回归 $r_{i,t} = a_i + \bv\beta_i'\mathbf f_t + u_{i,t}$ 的截距 $a_i$（因子为超额收益时）。Jensen 用 CAPM 回归的截距评价基金业绩，这一截距称为 Jensen's alpha [@jensen1968performance]。α 总是相对于某一个选定的模型而言：换一个模型，α 就变了。

**业界常见含义。** 至少有三种用法。第一，相对基准（如沪深 300、中证 500）的超额收益，例如“今年 alpha 10%”；第二，一类策略，“alpha 策略”通常指买入股票组合、同时卖空股指期货对冲市场风险的市场中性策略（见[多空组合与对冲](#glossary-long-short)）；第三，对个股收益的预测值或信号，“alpha 模型”“alpha 因子”即此义。Grinold 与 Kahn 把 alpha 定义为对残差收益（剔除基准相关部分之后）的预测 [@grinold2000active]，与第三种用法一致。

**本书用法。** $\alpha_{i,t}$ 是定价误差，本书模型中 $\alpha_{i,t} = \bv\theta'\mathbf z_{i,t-1}$，$\bv\theta \in \Real^L$；时间序列回归的截距记作 $a_i$（第 0 章 0.2 节“定价误差”，[定价误差](#glossary-pricing-error)）。

**常见混淆。** 相对基准的超额收益里包含了 β 偏离。例子：基准指数上涨 10%，一个对基准 β 为 1.2、Jensen α 为 0 的组合上涨约 12%（暂不考虑无风险利率），业界口径的“超额收益”约为 2%，但这 2% 全部来自更高的 β，学术口径的 α 为 0。反过来，一个 β 为 0.8 的组合在下跌市中“跑赢基准”，也未必有 α。

(glossary-beta)=
### beta（β）

**白话。** β 就是载荷，最常指对市场的载荷：市场涨 1%，这只股票平均涨多少。

**学术含义。** 单因子（CAPM）中 β 是对市场组合的载荷，$\beta_i = \Cov(r_i, f_{\text{mkt}})/\Var(f_{\text{mkt}})$；多因子时 β 泛指载荷向量 $\bv\beta_i$。

**业界常见含义。** “beta 收益”指承担市场或基准风险就能得到的收益，即指数本身的涨跌，与需要选股能力的“alpha 收益”相对。“smart beta”指按规则（如低波动、红利、价值、等权）而不是按市值加权构造的指数或指数基金，学术上更接近[因子投资](#glossary-factor-investing)：系统地获取某些风格因子的收益。“高 beta 股票”“beta 弹性”则与学术用法一致。

**本书用法。** β 即[载荷](#glossary-loading) $\bv\beta_{i,t} \in \Real^K$；单因子时可记作标量 $\beta_i$。

**常见混淆。** 在包含相应因子（如价值、低波动）的模型中，smart beta 产品的收益大多表现为对这些因子的载荷，而不是 α；相对 CAPM 或 Fama–French 三因子这类不含低波动因子的模型，低波动组合本身就常表现出正的 α。但业界宣传中，相对沪深 300 的超额常被称为 alpha。二者口径不同，前者问“模型能否解释”，后者问“是否跑赢某个指数”。

(glossary-excess-return)=
### 超额收益（excess return）

**白话。** 学术上的超额收益是减去无风险利率；业界的超额收益通常是减去基准指数。

**学术含义。** 超额收益 $R^e_{i,t} = R_{i,t} - R^f_{t-1}$，即零成本头寸（借入无风险资金买入资产）的收益。多空组合的收益本身就是超额收益。

**业界常见含义。** 常指相对基准指数（如沪深 300、中证 500、中证 1000）的超额，即“相对收益”，指数增强产品就以它为考核目标。与之相对，“绝对收益”指不以指数为参照、追求正收益的产品（常见于私募）。超额的计算方式也不统一：可以是收益率之差，也可以是净值之比（几何超额）。

**本书用法。** 超额收益一律指减去无风险利率，面板记号为 $r_{i,t}$（即 $R^e_{i,t}$，[记号表](notation.md)）。相对基准的收益差，本书称为“相对收益”或“相对基准的超额收益”，并注明基准。

**常见混淆。** 例子：某月沪深 300 上涨 2%，无风险利率为 0.2%，某指数增强产品上涨 3%。学术口径的超额收益为 $3\% - 0.2\% = 2.8\%$，业界口径的超额收益为 $3\% - 2\% = 1\%$。读产品报告中的“超额”时，先看减去的是什么。

(glossary-pricing-error)=
### 定价误差、异常收益（pricing error, abnormal return）

**白话。** 定价误差是模型解释不了的期望收益；异常收益是某个事件前后，实际收益超出“正常”收益的部分。

**学术含义。** 定价误差是相对于定价模型的 $\alpha_i = \E[r_i] - \bv\beta_i'\bv\lambda$，是一个期望值，即 [alpha](#glossary-alpha) 的学术含义。异常收益（abnormal return，AR）来自事件研究：先用事件之前的一段数据估计“正常收益”模型（例如市场模型 $R_{i,t} = a_i + \beta_i R_{\text{mkt},t} + u_{i,t}$，$R_{\text{mkt},t}$ 为市场指数收益），再计算事件窗口内的实际收益减去模型预测值，并在窗口内累加得到累计异常收益（CAR）。异常收益是逐期的已实现值，不是期望。

**业界常见含义。** 业界较少用“定价误差”一词。事件驱动策略（如业绩预告、指数成分调整、股东增持）中会用到“超额收益”“异常收益”，基准多为市场指数或行业指数，即“收益减去基准”。

**本书用法。** 定价误差记作 $\alpha_{i,t}$（第 0 章 0.2 节“定价误差”）；异常收益在用到事件研究的章节另行定义。

**常见混淆。** 定价误差是期望意义上的量，需要用长样本的平均来估计；异常收益是一次事件中的实现值，噪声很大，只有对大量事件平均之后才有意义。两者都依赖所选的“正常收益”模型。

(glossary-sdf)=
### 随机贴现因子、定价核（stochastic discount factor, pricing kernel）

**白话。** 随机贴现因子给未来的每个状态标一个数：那个状态下一块钱今天值多少，再除以该状态的概率。坏时候的数大，好时候的数小。

**学术含义。** SDF $m_{t+1}$ 满足 $P_t = \E_t[m_{t+1}x_{t+1}]$，是现代资产定价理论的统一框架 [@cochrane2005asset]；线性因子模型等价于 SDF 是因子的线性函数。定价核与 SDF 通常同义。

**业界常见含义。** 国内量化业界很少使用这一概念。业界与估值实务中常说的“折现率”，指把未来现金流折算为现值时用的利率，例如现金流折现模型中的加权平均资本成本，对每项资产是一个数。

**本书用法。** SDF 记作 $m_{t+1}$（面板部分 $m_t$），本书模拟市场中 $m_t = 1 - \mathbf b'(\mathbf f_t - \bv\mu)$，$\mathbf b \in \Real^K$（第 0 章 0.2 节“随机贴现因子”与 0.5 节）。第 1 章从投资者的消费—储蓄选择推出 $m_{t+1} = \delta u'(C_{t+1})/u'(C_t)$，幂效用下为 $\delta(C_{t+1}/C_t)^{-\gamma}$（[1.2 节](#sec-ch1-sdf)）；第 0 章的 $m_t$ 对应第 1 章的 $R^f_t m_{t+1}$。与“主观贴现因子”等用法的区别见[贴现因子](#glossary-discount-factor)。

**常见混淆。** SDF 是一个随状态变化的随机变量，对所有资产相同；折现率是对某一项资产而言的一个数，不同资产不同。二者的联系是：资产的期望收益就是它的折现率，而期望收益由资产收益与 SDF 的协方差决定，$\E[R^e] = -\Cov(m, R^e)/\E[m]$；无风险利率满足 $R^f = 1/\E[m]$。Cochrane 的会长演讲就以“折现率”为题，讨论期望收益为何随时间与资产变化 [@cochrane2011presidential]。

(glossary-risk-free)=
### 无风险利率（risk-free rate）

**白话。** 无风险利率是把钱放在没有违约风险的资产上、期初就已确定的收益。实证中要选一个利率当作它的代理变量。

**学术含义。** 美国股市的实证研究通常用一个月期国库券利率作为月度无风险利率。A 股研究中常见的代理变量有：一年期定期存款利率（折算为月利率）、上海银行间同业拆放利率（Shibor）、短期国债收益率、银行间回购利率等。不同代理变量的水平与波动差别不小，早期利率管制时期尤其如此。CH3 [@liu2019size] 使用的无风险利率口径，需要核对原文（待核实）。

**业界常见含义。** 计算夏普比率等指标时，业界常用一年期定期存款利率、短期国债或货币基金收益率，也有直接取 0 的；评价相对收益产品时，往往根本不减无风险利率，而是减基准指数（见[超额收益](#glossary-excess-return)）。

**本书用法。** 面板与模拟数据部分，第 $t$ 期适用的无风险总收益记作 $R^f_{t-1}$，在第 $t-1$ 期末已知；理论章节（第 1 章起）写作 $R^f_t$，适用于从 $t$ 到 $t+1$，二者只差时点标号；模拟器不单独生成无风险利率，归一化 $\E[m_t] = 1$ 相当于 $R^f = 1$（[记号表](notation.md)）。A 股实证中使用的代理变量在第 15 章说明。

**常见混淆。** 月度数据中，无风险利率每月只有零点几个百分点，看似可以忽略，但它会改变时间序列回归的截距与夏普比率；比较不同论文的结果时，应先确认它们用的是哪个代理变量。

(glossary-risk-aversion)=
### 风险厌恶（risk aversion）

**白话。** 学术上的风险厌恶是效用函数的一个参数，说的是投资者有多不愿意让消费随状态起伏；业界说的“风险偏好”，多指市场整体的情绪，或者某位客户能承受多大的亏损。

**学术含义。** 风险厌恶由效用函数的弯曲程度刻画。相对风险厌恶系数 $-Cu''(C)/u'(C)$ 在幂效用 $u(C) = C^{1-\gamma}/(1-\gamma)$ 下是常数 $\gamma$：$\gamma$ 越大，边际效用随消费下降得越快，坏时候的一元钱越值钱，SDF $m_{t+1} = \delta(C_{t+1}/C_t)^{-\gamma}$ 的波动越大（[第 1 章 1.1 节](#sec-ch1-two-period)）。例如 $\gamma = 2$ 时，消费低 10% 的状态，边际效用高约 23%（$0.9^{-2} \approx 1.23$）。在对数正态模型中，风险溢价与 $\gamma$ 成正比，红利索取权的对数溢价为 $\gamma\rho\sigma_c\sigma_d$（[1.4 节](#sec-ch1-lognormal)）。幂效用下跨期替代弹性是 $1/\gamma$，风险厌恶与跨期替代被同一个参数绑定；Epstein 与 Zin 的递归效用把二者分开 [@epstein1989substitution]（第 7 章）。

**业界常见含义。** 卖方策略常说“市场风险偏好回升”“风险偏好下降”，指投资者整体愿意承担风险的程度随行情、政策与情绪变化，常结合成交额、融资余额、股债收益差等指标观察。财富管理中的“风险承受能力”“风险等级”，是通过问卷对客户所做的分类，用于产品的适当性管理。

**本书用法。** 风险厌恶指偏好参数，幂效用下即风险厌恶系数 $\gamma$（[记号表](notation.md)），不用来描述市场情绪。

**常见混淆。** 第一，“风险偏好上升”不等于模型中的 $\gamma$ 下降：幂效用模型中 $\gamma$ 是常数，期望收益随时间变化要靠其他机制，例如时变的消费分布或习惯形成（第 6、7 章）。第二，风险厌恶高不意味着每一项资产的期望收益都高：期望收益由资产收益与 SDF 的协方差决定，$\gamma$ 放大的是这一协方差的补偿；在消费增长低时收益高的资产像保险，$\gamma$ 越大，它的期望收益越低（[1.3 节](#sec-ch1-risk)）。第三，幂效用下 $\gamma$ 同时是跨期替代弹性的倒数，报告“$\gamma$ 的估计值”时要说明效用函数的形式（[常见误区](#sec-ch1-pitfalls)）。

(glossary-factor-investing)=
### 因子投资（factor investing）

**白话。** 学术上的因子投资，是长期、系统地持有少数几个被反复证实有正平均收益的因子组合，以获取风险溢价；国内量化业界说的因子投资，多数时候指“多因子选股”：用大量信号给股票打分，再通过组合优化追求跑赢基准。

**学术含义。** 因子投资源于因子模型与异象文献：如果价值、动量、规模、低波动、盈利质量等因子长期有正的风险溢价，投资者就可以按规则持有相应的多空组合，或在市值加权组合的基础上向这些因子倾斜（tilt）。Ang 把资产配置进一步理解为对底层因子风险的配置 [@ang2014asset]。学术研究关心的问题是：溢价为什么存在（风险补偿还是错误定价，第 8 章）；发表之后是否衰减 [@mclean2016does]；扣除交易成本之后是否还在（第 26 章）；少数几个因子能否概括大量异象（第 16、18 章）。因此，学术意义上的因子投资通常因子数量少、换手率低、持有期长，并强调每个因子的经济解释。

**业界常见含义。** 海外资产管理行业所说的 factor investing 与学术含义接近，常见产品是按规则构造的 smart beta 或风格指数基金（见 [beta](#glossary-beta)），以及持有多个风格多空组合的风格溢价产品。国内量化业界说的“因子投资”“多因子策略”，多数时候指 alpha 多因子选股：从因子库中选出大量信号（量价、基本面、分析师预期、另类数据等），用线性加权或机器学习合成一个打分，再在风险模型的约束下做组合优化，控制行业与风格暴露，追求相对基准的超额收益（指数增强）或市场中性收益。这类策略往往使用成百上千个信号，量价类信号占比高，换手率高，评价时更看重预测力（[IC](#glossary-ic)）、超额收益、回撤与容量，而不是每个信号的经济解释。业界还有“风格轮动”或“风格择时”，即根据宏观或市场状态调整对风格因子的暴露，学术上称为因子择时，其可行性在文献中仍有争议。以上是通行用法，各机构的具体定义与流程不一。

**本书用法。** 本书中的“因子投资”取学术含义：系统地持有因子组合以获取风险溢价。业界意义上的多因子选股，本书称为“多信号选股”或“基于特征的收益预测”，它正是第四部分收益预测（第 22 章）与可实施性（第 26 章）研究的对象。

**常见混淆。** 第一，同一个“价值因子”在两种语境下的角色可能相反。在学术因子投资中，价值多空组合本身就是收益来源，要长期持有；在国内多因子选股中，价值可能只是打分中的一项信号，同时又作为风险模型中的风格暴露，被约束在接近基准的水平。第二，“有效”的标准不同：学术上看长期平均收益、风险溢价 $\bv\lambda$ 与相对于定价模型的 $\alpha$；业界看 IC、超额收益与回撤。第三，A 股卖空受限，学术多空组合的空头一侧难以实现，国内的因子投资更多以只做多的指数增强形式出现（见[多空组合与对冲](#glossary-long-short)）。

## 二、绩效与风险指标

(glossary-sharpe)=
### 夏普比率（Sharpe ratio）

**白话。** 夏普比率是“每承担一单位波动，平均多赚多少”：超额收益的均值除以它的标准差。

**学术含义。** 夏普比率 $\mathrm{SR} = \E[R^e]/\sigma(R^e)$，分子是减去无风险利率的超额收益，Sharpe 最初称之为 reward-to-variability ratio [@sharpe1966mutual]。理论上，任何资产或组合的夏普比率的绝对值都不超过 $\sigma(m)/\E[m]$（Hansen–Jagannathan 界 [@hansen1991implications]，第 3 章）。月度数据年化时，均值乘以 12、标准差乘以 $\sqrt{12}$，夏普比率因而乘以 $\sqrt{12} \approx 3.46$。这一换算假定各月收益不相关；收益正自相关时（例如净值被平滑的私募产品），月度标准差低估了长期波动，年化夏普比率会被高估。

**业界常见含义。** 产品评价中，夏普比率常用日度或周度净值收益计算后年化（日度乘以 $\sqrt{250}$、$\sqrt{252}$，或按实际交易日数换算，A 股每年约 240 多个交易日；周度乘以 $\sqrt{52}$）；无风险利率可能取存款利率、短期国债收益率或 0（见[无风险利率](#glossary-risk-free)）。

**本书用法。** 夏普比率一律指超额收益（减去无风险利率）的均值除以标准差，报告时注明频率与是否年化。

**常见混淆。** 月度 0.2 与年化约 0.69 是同一个夏普比率，比较前先统一频率。多空组合的收益本身就是超额收益，不必再减无风险利率。夏普比率的估计误差很大：样本只有几年时，年化 1 与 0.5 往往难以在统计上区分（标准误见第 12 章）。对相对基准的超额收益计算的类似比率是[信息比率](#glossary-ir)。

(glossary-ir)=
### 信息比率（information ratio）

**白话。** 信息比率是“每承担一单位相对风险，多赚多少”：扣除参照物之后的残差收益的均值，除以残差的波动。

**学术含义。** Treynor 与 Black 把市场模型回归 $R^e_{i,t} = a_i + \beta_i R^e_{\text{mkt},t} + \varepsilon_{i,t}$ 中的 $a_i/\sigma(\varepsilon_i)$ 称为评估比率（appraisal ratio），并证明：残差互不相关时，在市场组合上加入最优的积极头寸后，组合夏普比率的平方等于市场夏普比率的平方加各资产评估比率的平方和 [@treynor1973use]。Grinold 与 Kahn 把信息比率定义为残差收益（相对基准、剔除 β 之后）的期望除以残差风险 [@grinold2000active]。二者形式上是一回事，只是参照物不同：前者是定价模型，后者是基准组合。“主动管理基本定律”$\mathrm{IR} \approx \mathrm{IC}\sqrt{\mathrm{BR}}$ 中的 IR 也是这一定义，但指事前按最优方式使用信号可达到的值，依赖信号相互独立、组合不受约束等简化假设（[IC](#glossary-ic)）；实际的事后信息比率受只做多等约束时通常更低。

**业界常见含义。** 常用“超额收益 ÷ 跟踪误差”：超额收益是产品收益减基准收益（不调整 β），跟踪误差是这一差值的标准差，通常年化。它是指数增强产品的核心考核指标，年化方式各机构不一。

**本书用法。** 信息比率指残差收益均值除以残差标准差，并注明参照物（定价模型或基准）以及是否调整 β；Treynor–Black 意义上的称为“评估比率”。

**常见混淆。** 业界口径不调整 β：组合对基准的 β 为 1.2 时，上涨市中“超额收益 ÷ 跟踪误差”偏高，其中一部分来自 β 偏离而不是选股能力（见 [alpha](#glossary-alpha) 的例子）。跟踪误差很小的指数增强产品可以有很高的信息比率，夏普比率却与基准指数相近。

(glossary-risk)=
### 风险（risk）

**白话。** 学术上的风险关心的是“在坏时候亏不亏”；业界的风险关心的是“会不会亏、亏多少、波动多大”。

**学术含义。** 资产定价中，能得到补偿（带来更高期望收益）的只有系统性风险：期望超额收益由收益与 SDF 的协方差决定，$\E[R^e] = -\Cov(m, R^e)/\E[m]$（[随机贴现因子](#glossary-sdf)，第 1、3 章）；在因子模型中，就是对被定价因子的载荷（第 4 章）。与 SDF 不相关的异质性风险可以分散掉，理论上不应得到补偿。异质性风险本身也有专门研究，例如 Ang、Hodrick、Xing 与 Zhang 发现，相对 Fama–French 三因子的异质波动率高的股票，随后的平均收益反而低 [@ang2006cross]，即“异质波动率之谜”。这是一个收益异象，不是“异质性风险有补偿”的证据，方向恰好相反。

**业界常见含义。** 含义更宽：收益的波动率、[回撤](#glossary-drawdown)、亏损概率、VaR、跟踪误差，以及风险模型中的行业与风格暴露（[风险模型](#glossary-risk-model)），还包括流动性风险、信用风险、合规风险等。“风控”多指控制这些量，并不涉及它们是否得到补偿。

**本书用法。** 单说“风险”时，指收益的不确定性；讨论补偿时，明确写“系统性风险”或“对因子的载荷”。

**常见混淆。** “风险越高收益越高”只对系统性风险成立，而且是期望意义上的。一只股票的总波动很大，如果主要是异质波动，学术上并不要求它有更高的期望收益；两只波动相同的资产，在坏时候亏损的那一只风险更高，应有更高的期望收益。

(glossary-drawdown)=
### 回撤（drawdown）

**白话。** 回撤是净值从此前的最高点跌下来的幅度；最大回撤是历史上最深的一次。

**学术含义。** 第 $t$ 期的回撤为 $D_t = 1 - V_t/\max_{s \le t} V_s$，$V_t$ 为累计净值，最大回撤为 $\max_t D_t$。资产定价文献很少使用回撤，评价因子或异象主要看平均收益、夏普比率与 α；在对冲基金、CTA 的绩效评价文献中较常见。回撤依赖收益的路径与样本长度：对同一个策略，样本越长，最大回撤只会更大或不变，所以不同长度样本的最大回撤不宜直接比较。

**业界常见含义。** 核心指标之一：最大回撤、回撤恢复期（从前高跌下到重新创新高所用的时间），以及卡玛比率（Calmar ratio，年化收益 ÷ 最大回撤）。私募产品常设预警线、止损线，直接以净值回撤为依据；投资者也更看重收益的路径，而不只是平均收益。

**本书用法。** 本书主要用平均收益、夏普比率与 α 评价组合；讨论可实施性时（第 26 章）报告最大回撤，并注明样本区间。

**常见混淆。** 夏普比率相同的两个策略，最大回撤可以相差很大，因为收益分布的偏度、尾部与自相关都会影响回撤。回撤小也不等于风险小：卖出期权一类的策略可以长期回撤很小，却在少数极端行情中大幅亏损。

(glossary-significance)=
### 显著性（significance）

**白话。** 学术上说“显著”，指统计上能排除“纯属运气”；业界说“显著”，多指效果明显、回测好看。

**学术含义。** 统计显著指在给定的检验与显著性水平下拒绝原假设，常见做法是看 $t$ 值的绝对值是否超过约 2（5% 双侧水平）。$t$ 值依赖标准误的算法，要考虑自相关、截面相关与估计误差（第 12 章）；在同一批数据上试过很多信号时，阈值还要提高，Harvey、Liu 与 Zhu 主张新因子的 $t$ 值应超过 3 [@harvey2016and]（第 14 章）。还要区分经济显著：效应的大小是否有实际意义，例如年化几个基点的 α，即使 $t$ 值很大，也无足轻重。

**业界常见含义。** 常指“效果明显”：IC 均值高、分组收益单调、多空净值曲线平滑；也会看 $t$ 值或 $|t| > 2$ 的期数比例，后者是单期口径（见[横截面回归与 Fama–MacBeth](#glossary-fm)）。

**本书用法。** “显著”只指统计显著，并写明检验、标准误与显著性水平；效应大小另行讨论。

**常见混淆。** 统计显著不等于能赚钱：扣除交易成本、受卖空与容量限制之后，显著的异象可能无利可图（第 26 章）。能赚钱也不等于统计显著：一段时间的盈利可能是运气，样本短、波动大时，$t$ 值很难超过 2。不显著也不等于没有效果，可能只是样本不足以把它检验出来。

(glossary-ic)=
### IC、Rank IC、ICIR

**白话。** IC 衡量一个信号每期把股票排得准不准：期初的信号值与本期收益在横截面上的相关系数。

**学术含义。** 学术论文较少直接报告 IC，与之最接近的是 Fama–MacBeth 回归 [@fama1973risk]：每期把收益对信号做横截面回归，看斜率的时间平均与它的 $t$ 值（见[横截面回归与 Fama–MacBeth](#glossary-fm)）。

**业界常见含义。** 第 $t$ 期的 IC 是信号 $z_{i,t-1}$ 与收益 $r_{i,t}$ 在 $N$ 只股票上的 Pearson 相关系数，$\mathrm{IC}_t = \operatorname{corr}_i(z_{i,t-1}, r_{i,t})$；Rank IC 是二者排序之间的相关系数（Spearman 相关系数），对极端值不敏感，业界更常用。ICIR 是 IC 时间序列的均值除以标准差，衡量预测力的稳定性；有的机构还会乘以 $\sqrt{12}$ 年化（月度数据时），口径不一。Grinold 与 Kahn 的“主动管理基本定律”把信息比率近似写成 IC 乘以独立下注次数的平方根 [@grinold2000active]，这是 IC 在业界广泛使用的一个原因。

**本书用法。** 本书在需要时使用 IC、Rank IC 与 ICIR，并说明计算口径（相关系数类型、是否中性化、收益的期限、是否做行业或基准调整）。同一期所有股票的收益减去同一个无风险利率，不改变相关系数与斜率，所以 IC 与是否减去无风险利率无关。信号即特征 $z_{j,i,t-1}$（[记号表](notation.md)），逐期横截面回归的系数沿用第 0 章的记号 $\hat{\mathbf g}_t$（[因子、特征、载荷的关系](#sec-ch0-fcl)）。

**常见混淆。** IC 与 Fama–MacBeth 斜率之间有一个精确关系和两个近似关系，各有前提。精确关系：一元横截面回归 $r_{i,t} = g_{0,t} + g_{1,t} z_{i,t-1} + u_{i,t}$（含截距、等权 OLS）的斜率与同一股票样本上的 Pearson IC 满足

```{math}
:enumerated: false
\hat g_{1,t} = \mathrm{IC}_t \cdot \frac{\hat\sigma_{r,t}}{\hat\sigma_{z,t}} ,
```

其中 $\hat\sigma_{r,t}$、$\hat\sigma_{z,t}$ 是第 $t$ 期收益与信号的横截面标准差（标量），二者须用同一自由度（同为除以 $N$ 或同为除以 $N-1$），比值才不受影响。信号已标准化时 $\hat\sigma_{z,t} = 1$，但只在标准化所用的自由度下成立：按除以 $N$ 标准化的信号，按除以 $N-1$ 计算的标准差并不等于 1。第一个近似关系：信号已标准化、且 $\hat\sigma_{r,t}$ 各期变化不大（约为常数 $\hat\sigma_r$）时，斜率的时间平均 $\bar{\hat g}_1 \approx \hat\sigma_r\,\overline{\mathrm{IC}}$。第二个近似关系：在同样的前提下，Fama–MacBeth 的 $t$ 值 $\bar{\hat g}_1 / (\hat\sigma(\hat g_{1,t}) / \sqrt T)$ 约为 $\mathrm{ICIR} \times \sqrt T$，$T$ 为期数；这里的 ICIR 是未年化的“IC 均值除以 IC 标准差”，并且 IC 标准差的自由度与 Fama–MacBeth 中 $\hat\sigma(\hat g_{1,t})$ 的一致，不是上文乘以 $\sqrt{12}$ 的年化口径。横截面离散度随时间变化较大时（例如市场剧烈波动的月份），两者可以相差不少。Rank IC 对应的是“收益排序对信号排序”的回归，与原始收益的回归斜率只有近似关系。IC 高也不等于多空收益高、更不等于有 α：IC 不区分预测力来自载荷还是定价误差。

(glossary-group-style)=
## 三、风格与特征名称

(glossary-value-growth)=
### 价值与成长（value, growth）

**白话。** 学术上的价值股是“便宜”的股票，成长股是“贵”的股票；业界的成长股则是“增长快”的股票。

**学术含义。** 价值与成长是按估值指标排序得到的名称。Fama–French 三因子按账面市值比（B/M）排序，高 B/M 组为价值股、低 B/M 组为成长股，HML 是二者的收益差 [@fama1993common]；CH3 在中国市场改用盈利市值比（EP），价值因子称为 VMG [@liu2019size]（构造见第 15、16 章）。因此，学术上的“成长股”通常就是按估值排序后的低 B/M（或低 EP）组，是排序意义上的名称，并不要求营收或利润增速高。市场给一只股票高估值，可能是因为预期增长高，也可能是因为折现率低（第 6 章）。

**业界常见含义。** 价值通常指低市盈率（PE）、低市净率（PB）、高股息的股票，例如银行、公用事业与红利指数的成分股；成长指营收、利润增速高的股票，常用营收增长率、净利润增长率或分析师一致预期增速衡量。风格指数的编制规则各不相同，有的同时使用估值与增速指标。

**本书用法。** 价值与成长取学术含义，并注明排序变量（B/M 或 EP）；指增速时写作“高增长股票”。

**常见混淆。** 两种“成长股”重合但不相同：高增速的公司往往估值也高，但低 B/M 组中也有增速不高、只是估值高的股票，高增速的公司也可能估值不高。读到“成长跑赢价值”时，先问是按什么分组的。

(glossary-pd)=
### 价格—红利比、市盈率与股息率（price-dividend ratio, P/E, dividend yield）

**白话。** 三者都是价格与公司回报的比较，但分母不同：价格—红利比用价格除以红利，市盈率用价格除以盈利，股息率则反过来，用红利除以价格。

**学术含义。** 价格—红利比 $P/D$ 与它的倒数股息率 $D/P$ 是资产定价理论中最常用的估值比率，因为红利是股东实际得到的现金流，价格等于未来红利的贴现和（[第 1 章 1.5 节](#sec-ch1-lucas)）。在红利增长独立同分布的模型中，$P/D$ 是常数，可以写成 Gordon 增长模型 $P/D = G/(\E[R] - G)$，$G$ 为红利的期望总增长；而数据中市场整体的 $P/D$ 波动很大，并对未来收益有一定的预测力，这是收益可预测性研究的核心问题之一 [@cochrane2011presidential]（第 6 章）。横截面研究按估值排序时还常用盈利价格比 EP 与账面市值比 B/M（见[价值与成长](#glossary-value-growth)）。

**业界常见含义。** 国内最常用的估值指标是市盈率（PE，即 $P/E$，价格与每股收益之比），有静态、滚动 12 个月（TTM）与预测等口径；股息率在红利策略与高股息指数中常用；“价格—红利比”这一说法业界很少使用。

**本书用法。** $P/D$ 称“价格—红利比”，不称“市盈率”；市盈率只指 $P/E$；$D/P$ 称股息率。例如股价 40 元、每股红利 1 元、每股收益 2 元，价格—红利比为 40，市盈率为 20，股息率为 2.5%（与第 1 章 1.5 节的例子相同）。

**常见混淆。** 把 $P/D$ 叫作市盈率。二者相差一个分红比例：$P/D = (P/E)/(D/E)$，分红比例为 50% 时，价格—红利比是市盈率的两倍。不分红的公司没有有限的价格—红利比，却可以有市盈率。第 1 章“独立同分布时价格—红利比为常数”是模型的结论，不是说现实中的估值比率不变；后者正是第 6 章要解释的现象。

(glossary-momentum)=
### 动量（momentum）

**白话。** 动量是“过去涨得多的，接下来还会涨得多”。

**学术含义。** 最常见的是截面动量：按过去 3～12 个月的累计收益给股票排序，买入赢家、卖出输家。Jegadeesh 与 Titman 发现，这样的组合在随后 3～12 个月有显著的正收益 [@jegadeesh1993returns]（第 15 章）。常用的构造取过去 12 个月、跳过最近 1 个月的累计收益（“12-1”），跳过最近一个月是为了避开短期反转：上个月涨得多的股票，下个月的平均收益反而偏低。时序动量（time-series momentum）是另一个概念：每个资产只看自己过去 12 个月的超额收益，为正就做多、为负就做空。Moskowitz、Ooi 与 Pedersen 在股指、债券、商品与外汇期货上都发现了这一现象 [@moskowitz2012time]（见[时序与截面](#glossary-ts-cs)）。

**业界常见含义。** 选股中的“动量因子”与学术截面动量接近，也包括更短窗口的价格趋势，并常与过去 1 个月左右的“反转因子”并列使用。CTA（管理期货）中的“趋势跟踪”则接近时序动量。

**本书用法。** 单说动量，指截面动量，并注明窗口（如 12-1）；时序动量明确写出。

**常见混淆。** A 股与美国不同，例如 Liu、Stambaugh 与 Yuan 发现中国股市没有动量效应，但有反转效应 [@liu2019size]。因此，美国市场上“12-1 动量”的结论不能直接搬到 A 股，回测时要看清窗口以及是否跳过最近一个月。截面动量是相对的：所有股票都涨时，它仍然做空涨得少的；时序动量是绝对的，可以同时做多所有资产。

(glossary-liquidity)=
### 流动性（liquidity）

**白话。** 学术上的流动性，是“一只股票好不好买卖”；业界常说的流动性，多指“市场上钱多不多”。

**学术含义。** 有两个层面。一是个股特征：买卖的成本与价格冲击。常用 Amihud 非流动性指标，即日收益的绝对值除以当日成交金额，再取时间平均；非流动性高的股票平均收益较高 [@amihud2002illiquidity]。换手率、买卖价差也常作为代理变量。二是流动性风险：Pástor 与 Stambaugh 构造了全市场流动性的时间序列，发现收益对市场流动性变化更敏感（流动性 β 高）的股票，平均收益更高 [@pastor2003liquidity]。前者是特征，后者是载荷。

**业界常见含义。** 常指宏观或资金面的流动性：货币政策松紧、M2 与社会融资规模增速、银行间资金利率、北向资金与两融资金的流入等，例如“流动性宽松利好股市”。说某只股票“流动性差”时，含义与学术上的个股特征接近。

**本书用法。** 流动性指个股或市场的交易便利程度，并区分“流动性特征”与“流动性风险（载荷）”；资金面的含义写作“资金面”或“货币信用环境”。

**常见混淆。** 资金面宽松与个股流动性好是两个概念：前者是宏观变量，后者是股票属性。学术上的“流动性溢价”指非流动股票或流动性 β 高的股票得到的额外期望收益，不是“资金宽松带来的上涨”。

(glossary-turnover)=
### 换手率（turnover）

**白话。** 个股换手率是一段时间内成交的股数占流通股的比例；组合换手率是组合在调仓时换掉了多少持仓。

**学术含义。** 个股换手率是成交量除以流通股本，是常见的股票特征：可以作为流动性的代理变量，也常被解释为投资者分歧或投机情绪的度量。中国市场中换手率的作用尤其突出：Liu、Stambaugh 与 Yuan 在 CH3 的基础上加入按异常换手率构造的情绪因子，得到四因子模型 CH4 [@liu2019size]。

**业界常见含义。** 一是个股的换手率因子，A 股业界通常把它当作负向信号：换手率高的股票，随后的收益偏低。二是组合换手率，即每期买卖金额占组合规模的比例，常年化报告，例如“年化双边换手 20 倍”，单边或双边的口径不一。组合换手率直接决定交易成本，是评价策略可实施性的核心指标。

**本书用法。** 写明是“个股换手率”还是“组合换手率”；组合换手率注明单边或双边。

**常见混淆。** “换手率因子”说的是股票特征，“策略换手率高”说的是组合调仓频繁，二者是不同的量。用换手率等短期量价信号选股时，信号变化快，组合换手率往往很高，扣除交易成本后收益可能大幅下降（第 26 章）。

(glossary-size)=
### 规模（size）

**白话。** 学术上的规模就是公司的市值；业界的规模还可能指一只产品管了多少钱。

**学术含义。** 规模是股票的市值（股价乘以股数），作为特征时通常取对数；规模因子 SMB 是小市值组合减大市值组合的收益 [@fama1993common]。A 股的小市值股票还含有“壳价值”：在 IPO 受管制时，小公司可能被借壳上市，股价中有一部分反映这一可能性。CH3 因此剔除市值最小的 30% 的股票后再构造因子 [@liu2019size]（第 17 章）。

**业界常见含义。** 选股中的“市值因子”“大小盘风格”与学术含义一致，中证 1000、国证 2000 等指数常代表小盘风格。此外，“规模”还常指产品或管理人的资产管理规模（AUM），例如“百亿私募”；“规模大了策略失效”说的是策略容量：资金越多，交易的价格冲击越大，超额收益越难维持。

**本书用法。** 规模指市值；管理规模写作“资产管理规模”，容量写作“策略容量”（第 26 章）。

**常见混淆。** “小盘因子失效”是股票收益的问题，“规模大了做不出超额”是容量与交易成本的问题，二者不同，但相互关联：小市值股票的流动性差，偏向小盘的策略容量往往更小。

(glossary-quality)=
### 质量（quality）

**白话。** 学术上的质量多指“盈利能力强”；业界的质量是一揽子“好公司”指标。

**学术含义。** 最常见的是盈利能力。Novy-Marx 发现，资产毛利率（毛利 ÷ 总资产，毛利为营业收入减营业成本）高的公司平均收益更高；盈利能力强的公司往往估值也高，所以这一策略与价值策略负相关，二者结合的效果更好 [@novy2013other]。Fama–French 五因子模型中的 RMW 是营业盈利能力（营业利润 ÷ 账面权益）高的组合减低的组合的收益（robust minus weak）[@fama2015five]。也有研究把盈利、增长、安全性（低杠杆、低波动）与派息合成一个质量分数，例如 Asness、Frazzini 与 Pedersen 的 QMJ（quality minus junk）因子 [@asness2019quality]（第 15、16 章）。

**业界常见含义。** 含义更宽：ROE 高且稳定、负债率低、经营现金流好、应计项目少（盈利“含金量”高）、财务造假与商誉减值风险低等，常合成一个质量因子，或用来剔除“雷股”。各机构的定义差别很大。

**本书用法。** 质量指盈利能力类特征，并注明具体变量（资产毛利率、营业盈利能力、ROE 等）。

**常见混淆。** 同叫“质量因子”，学术论文中可能只是一个盈利指标，业界可能是十几个指标的合成，二者的收益与风险特征不能直接比较。“好公司”也不等于“好股票”：质量高的公司估值也可能高，期望收益取决于价格是否已经反映了质量。

(glossary-style)=
### 风格（style）

**白话。** 风格是一个组合“偏向哪一类股票”：大盘还是小盘，价值还是成长。

**学术含义。** 风格指组合对某些特征或因子的系统性倾斜。Sharpe 提出基于收益的风格分析：把基金收益对一组资产类别指数的收益回归，约束系数非负且和为 1，用系数刻画基金实际的资产配置，即它的风格 [@sharpe1992asset]。在因子模型中，风格就是对规模、价值、动量等因子的载荷。

**业界常见含义。** 一是市场风格：“大小盘切换”“成长价值切换”，以及据此调整配置的“风格轮动”。二是风险模型中的风格因子：Barra 类模型中的规模、价值、动量、波动率、流动性等，与行业因子并列（[风险模型](#glossary-risk-model)）。“风格暴露”“风格漂移”分别指组合对这些因子的暴露及其随时间的偏离。

**本书用法。** 风格指组合对特征或因子的载荷；风格轮动作为因子择时讨论（见[择时](#glossary-timing)）。

**常见混淆。** Barra 的风格因子收益来自横截面回归，与学术上按排序构造的多空因子（如 SMB、HML）口径不同，即使名称相同，数值也不一样。风格轮动是对风格的择时，与长期持有风格因子的学术[因子投资](#glossary-factor-investing)不是一回事。

(glossary-group-methods)=
## 四、模型与方法

(glossary-factor-model)=
### 因子模型（factor model）

**白话。** 因子模型是“收益 = 载荷 × 因子 + 其余部分”这一类模型的统称，但不同的因子模型想回答的问题不同。

**学术含义。** 至少要区分三类。**定价模型**解释期望收益的横截面差别，核心是 $\E[r_i] = \bv\beta_i'\bv\lambda$ 与 $\alpha_i = 0$ 的检验，例如 CAPM、Fama–French 三因子 [@fama1993common]、CH3 [@liu2019size]。**统计因子模型**用主成分分析等方法从收益的协方差中提取因子，目标是解释共同波动；IPCA 把载荷设为特征的函数，兼顾二者 [@kelly2019characteristics]。**风险模型**（见[风险模型](#glossary-risk-model)）以预测协方差为目标。

**业界常见含义。** “多因子模型”在业界常指多因子选股模型：把多个 alpha 信号加权合成一个综合打分，据以选股或作为组合优化的预期收益输入；也常指 Barra 类风险模型。两种用法的目标完全不同。

**本书用法。** 本书的“因子模型”默认指定价模型；指统计因子模型、风险模型或多因子选股模型时，会明确说明。第 0 章的模拟市场同时是一个定价模型（$\bv\theta = \mathbf 0$ 时）与一个协方差结构已知的统计模型。

**常见混淆。** 业界的“多因子选股模型”中的“因子”是信号，模型输出的是预测值；学术的“多因子模型”中的因子是收益序列，模型检验的是定价误差。前者做得好，意味着预测准；后者成立，意味着没有 α。

(glossary-ccapm)=
### 消费 CAPM（consumption CAPM）

**白话。** 消费 CAPM 说，一项资产的期望收益高低，取决于它是不是在消费低、日子难过的时候也跟着亏钱。它是只有一个因子的 β 模型，因子是消费增长。

**学术含义。** 把 SDF 在消费增长的均值处线性化，$m \approx \E[m]\left[1 - \gamma(\Delta c - \mu_c)\right]$，得到 $\E[R^e] \approx \beta_{\Delta c}\lambda_c$：$\beta_{\Delta c}$ 是超额收益对消费增长做时间序列回归的斜率，$\lambda_c = \gamma\sigma_c^2$ 是消费增长的风险溢价，在连续时间中这一关系精确成立 [@breeden1979intertemporal]（[第 1 章 1.4 节](#sec-ch1-ccapm)）。消费增长是不可交易的因子，$\lambda_c$ 不等于它的均值：第 1 章的默认假设参数下，$\lambda_c = 0.08\%$，而 $\E[\Delta c] = 2\%$。消费模型与数据的定量矛盾（股权溢价之谜）见第 7 章 [@mehra1985equity]，用广义矩方法估计偏好参数见第 11 章。

**业界常见含义。** 国内量化业界很少直接使用消费 CAPM。与它相近的是宏观因子模型与宏观配置：把 GDP、社会消费品零售总额、PMI 等宏观数据的变化当作“宏观因子”，计算股票或行业对它们的敏感度，或者按“消费复苏”一类的宏观判断配置行业。业界所说的“消费”还常指消费行业（食品饮料、家电等）的股票，与消费 CAPM 中的消费增长不是一回事。

**本书用法。** 消费 CAPM 指以对数消费增长 $\Delta c$ 为唯一因子的 β 模型 $\E[R^e] \approx \beta_{\Delta c}\lambda_c$；$\lambda_c$ 专指消费增长的风险溢价（[记号表](notation.md)）。

**常见混淆。** 第一，把 $\E[\Delta c]$ 当作消费增长的风险溢价，在第 1 章的默认假设参数下会把期望超额收益高估 25 倍（[常见误区](#sec-ch1-pitfalls)）；不可交易因子的风险溢价要用横截面回归或模拟组合另行估计（第 4、10 章）。第二，消费行业的股票不一定有高的 $\beta_{\Delta c}$：决定它的是收益与总消费增长的协方差，不是公司卖什么产品。第三，中国的消费数据频率低、样本短、口径多，直接用它检验定价模型很困难（[A 股视角](#sec-ch1-ashare)）。

(glossary-risk-model)=
### 风险模型、Barra 模型（risk model）

**白话。** 风险模型回答的是“这个组合未来波动多大、风险来自哪里”，而不是“哪只股票期望收益高”。

**学术含义。** 学术资产定价较少单独讨论“风险模型”，与之相关的是协方差矩阵的因子结构估计。在本书的模型中，给定期初特征，收益的条件协方差矩阵为 $\mathbf B_t\bv\Sigma_f\mathbf B_t' + \sigma_\varepsilon^2\mathbf I_N$（$N\times K$、$K\times K$、$K\times N$ 相乘再加 $N\times N$，得 $N\times N$）。

**业界常见含义。** Barra（现属 MSCI）类风险模型中，现行的中国模型（如 CNE5、CNE6）以及美国模型 USE4 之后的版本，把股票收益写成“国家因子 + 行业因子 + 风格因子 + 特异收益”（早期版本没有单独的国家因子）；暴露取行业哑变量与标准化的风格特征，因子收益由每期横截面回归估计，再由因子收益的时间序列估计因子协方差矩阵、由残差估计特异风险。用途是预测组合风险与跟踪误差、做风险归因与业绩归因，以及在组合优化中约束风格与行业暴露。国内券商与第三方也有类似的自建风险模型。

**本书用法。** 本书在第 0 章说明 Barra 式横截面回归是“特征决定载荷”且 $\bv\Gamma = \mathbf I_{L+1}$ 的特例（[因子、特征、载荷的关系](#sec-ch0-fcl)）；统计因子与协方差结构见第 23 章，组合构造中的风险约束见第 26 章。

**常见混淆。** 风险模型的风格因子是为解释协方差而选的，不一定有风险溢价；定价模型的因子是为解释期望收益而选的。一个风格因子在风险模型中很重要（解释了大量共同波动），在定价模型中却可能不被定价，反之亦然。

(glossary-fm)=
### 横截面回归与 Fama–MacBeth（cross-sectional regression, Fama–MacBeth）

**白话。** 横截面回归是固定一期、沿股票跑的回归，回答“这一期，特征或载荷高的股票多赚了多少”；Fama–MacBeth 是每期各跑一次横截面回归，再对系数求时间平均，用系数的时间序列波动计算标准误。

**学术含义。** 第 $t$ 期的横截面回归把 $N$ 只股票的收益 $\mathbf r_t$ 对股票层面的变量回归，解释变量可以是载荷估计值 $\hat{\bv\beta}_i$，也可以是期初特征 $\tilde{\mathbf z}_{i,t-1}$，得到当期的系数 $\hat{\mathbf g}_t$。Fama–MacBeth 程序 [@fama1973risk] 取 $\bar{\mathbf g} = T^{-1}\sum_t\hat{\mathbf g}_t$ 为点估计，逐分量以 $\hat g_{j,t}$ 的时间序列标准差除以 $\sqrt T$ 为标准误；同期股票之间的相关被压缩进每期的一个系数，因而自动计入。对载荷回归时，$\bar{\bv\lambda}$ 估计风险溢价 $\bv\lambda$；载荷需先由时间序列回归估计（两步法），由此带来的变量误差与 Shanken 修正 [@shanken1992estimation] 见第 10 章。

**业界常见含义。** 第一，Barra 类风险模型中的“因子收益”就是每期横截面回归的系数，解释变量是行业哑变量与标准化的风格暴露（[因子收益](#glossary-factor-return)、[风险模型](#glossary-risk-model)）。第二，卖方金工单因子测试中的“回归法”：每期把下期收益对因子值做横截面回归，通常同时放入行业哑变量与对数市值，即做行业与市值的[中性化](#glossary-neutralization)，得到因子收益序列与每期的 $t$ 值序列，再报告因子收益的均值（及其 $t$ 值）、$t$ 值绝对值的均值、$|t| > 2$ 的期数比例等。第三，[IC](#glossary-ic) 是信号与收益的横截面相关系数，与一元横截面回归的斜率只差一个比例。以上是通行用法，各机构的具体做法（加权方式、是否对因子值排序、控制哪些变量）不一。

**本书用法。** 横截面回归的系数记作 $\hat{\mathbf g}_t$（对特征）或 $\hat{\bv\lambda}_t$（对载荷），Fama–MacBeth 点估计记作 $\bar{\mathbf g}$ 或 $\bar{\bv\lambda}$，标准误按上面的时间序列标准差计算（[记号表](notation.md)）。几种回归的对比与模拟见[导读：几种回归](#sec-ch0-regs)（模拟在[续页](#sec-ch0-regs-sim)）。

**常见混淆。**

- 业界“$t$ 值序列”中的每期 $t$ 值，是**单期**横截面回归的 OLS $t$ 值，衡量这一期系数相对于这一期横截面噪声的大小；Fama–MacBeth 的 $t$ 值是系数的时间平均除以它的时间序列标准误，衡量平均补偿是否不为 0。二者不是一回事：一个特征可以在多数期都有很大的 $|t|$、而方向时正时负（[导读：几种回归（续）](#sec-ch0-regs-sim)的模拟中，$z_1$ 的每期 $t$ 值大于 2 与小于 $-2$ 的期数都超过 15%），平均补偿是否为正，要看 FM $t$ 值（见该页输出）。“$|t| > 2$ 的比例”同样是单期口径，不能当作显著性检验。
- 把全部股票与期数放在一起做一次混合回归，用同方差标准误时，同期残差的相关被忽略，标准误偏小、$t$ 值偏大；残差中含有同期共同的因子冲击时，偏差可以很大。按时间聚类的标准误见第 12 章。
- 时间序列回归的截距与横截面回归的截距含义不同。前者是每只股票一个，因子为可交易的超额收益时，它是这只股票的定价误差 α；后者是每期一个，是当期解释变量全为 0 的（假想）股票的拟合收益。对载荷回归时，它是载荷为 $\mathbf 0$ 的组合在这一期的拟合收益：若用超额收益回归且模型正确，它的时间平均应为 0；用总收益回归时，它估计零 β 资产的收益率。对特征回归时，它是特征全为 0 的基准股票的拟合收益，时间平均是这只基准股票的期望收益，不必为 0，例如第 0 章模拟中约为 $\mu_1$。无论哪种情形，它都不是某只股票的 α。

(glossary-neutralization)=
### 中性化（neutralization）

**白话。** 中性化是把一个信号中能被行业、市值等解释的部分去掉，只留下“与行业、市值无关”的那部分。

**学术含义。** 学术论文较少用“中性化”一词，更常说控制变量、行业调整（industry-adjusted）或特征调整收益（例如按规模、账面市值比与动量匹配基准组合的 DGTW 调整，DGTW 指 Daniel、Grinblatt、Titman 与 Wermers）。最接近的做法是“控制变量”：在 Fama–MacBeth 横截面回归 [@fama1973risk] 中同时放入信号与市值、行业等控制变量，看信号的系数（第 10 章）；或者做双重排序，先按市值分组，再在每个市值组内按信号排序，看信号的收益差。

**业界常见含义。** 每期在横截面上把信号对行业哑变量与对数市值（有时还有其他风格因子）做回归，取残差作为“中性化后的因子值”，再用它计算 IC、分组收益或构造组合。组合层面的“行业中性”“市值中性”则指组合对行业与市值的暴露与基准相同或为 0。

**本书用法。** 本书用“控制变量”与“残差化”的说法，并注明控制了哪些变量。被中性化的信号是特征 $z_{j,i,t-1}$（[记号表](notation.md)）；横截面回归的写法见第 0 章[因子、特征、载荷的关系](#sec-ch0-fcl)。

**常见混淆。** 由 Frisch–Waugh–Lovell 定理，收益对“信号与控制变量”做多元回归时信号的系数，等于收益对“残差化后的信号”做一元回归的系数（附录 A 讨论投影时给出证明）。这一等价有成立条件：两次回归用同一样本；残差化用的就是多元回归中的那一组控制变量，并且其中含常数项或完整的行业哑变量（使残差化后的信号均值为 0）；两步用同一加权方式（例如都用等权 OLS）；残差化之后不再做缩尾或标准化。业界常见的“中性化后再标准化”会按标准差改变系数的尺度，但不改变符号；对残差做 Rank 化，或者一步用 WLS、另一步用等权 OLS，等价就不再成立。IC 也不同：中性化后的信号与原始收益的相关系数是半偏相关系数（part 或 semipartial correlation），不等于偏相关系数，因为收益本身没有被残差化。双重排序是同一思路的非参数版本，但在特征相关或关系非线性时，结果可能与回归控制不同。

(glossary-long-short)=
### 多空组合、对冲（long-short, hedged）

**白话。** 多空组合是同时买入一组股票、卖空另一组股票；对冲是用一个空头头寸抵消不想要的风险。

**学术含义。** 学术研究中的多空组合通常假定可以无成本地卖空单只股票：例如买入特征最高的 10%、卖空最低的 10%，两条腿的金额相等，组合期初不花钱，收益就是超额收益。因子（如 SMB、HML）与异象的收益大多按这种方式计算，通常不扣交易成本与融券成本。

**业界常见含义。** A 股融券规模小、成本高，单只股票很难大规模做空。业界常见的做法是买入股票组合、卖空股指期货（沪深 300、中证 500、中证 1000 等股指期货）对冲市场风险，称为“市场中性”或“alpha 策略”，其收益约为股票组合相对期货标的指数的超额，减去对冲成本（包括期货贴水造成的基差损失）。市场中性产品还要为股指期货空头留出保证金，这部分资金不能买入股票，摊薄了收益；期货升水时，卖空期货的基差反而贡献正收益。另一类主流产品是“指数增强”，也是公募量化的主力：只做多，在跟踪某个指数的同时争取超额收益，并限制跟踪误差，满足投资者“既要指数的 β、又要超额收益”的需求。

**本书用法。** 多空组合指学术意义上的零成本组合，权重向量 $\mathbf w_t \in \Real^N$ 满足 $\mathbf w_t'\mathbf 1_N = 0$（第 0 章[因子、特征、载荷的关系](#sec-ch0-fcl)）；可实施性与交易成本在第 26 章讨论。

**常见混淆。** 学术多空收益不等于业界可实现的收益：A 股的空头腿基本无法照做，一个异象的收益若主要来自空头腿，只做多或用期货对冲都拿不到它。评价 A 股的信号时，应当把多头相对基准的超额单独列出。

(glossary-oos)=
### 样本外（out-of-sample）

**白话。** 样本外就是用估计模型时没有用过的数据来检验模型。

**学术含义。** 预测与机器学习资产定价研究中，样本外检验通常按时间顺序进行：只用第 $t$ 期以前的数据估计模型（滚动窗口或扩展窗口），预测第 $t$ 期，再逐期向前推进；或者把样本按时间分为训练集、验证集与测试集，测试集只在最后用一次 [@gu2020empirical]。样本外 $R^2$ 等指标都以这种划分为前提。

**业界常见含义。** “回测”指在历史数据上模拟一个策略的表现；“模拟盘”指用实时行情模拟交易而不投入资金；“实盘”指真实资金运行。业界常说的“样本外”，有时指回测区间之后的一段历史，有时指上线之后的实盘表现。

**本书用法。** 样本外指估计（包括选模型、调参数、选特征）时完全没有用过的数据，并且只使用每个时点之前可得的信息（第 0 章 0.3 节的时点约定）。

**常见混淆。** 回测不等于样本外：如果信号的构造、参数或股票池是在看过整个回测区间之后才确定的，回测结果就是样本内的。反复修改策略直到回测好看，即使每次都“只用历史数据”，也是在用测试集选模型，会造成过拟合；尝试过的方案越多，回测中最好的结果越可能只是运气（多重检验问题，第 14 章讨论；样本外检验的计量见第 13、19 章）。

(glossary-predictability)=
### 可预测性与市场有效（predictability, market efficiency）

**白话。** 收益能被预测，不等于市场无效：风险补偿本身随时间变化，也会让收益可以预测。

**学术含义。** 检验市场是否有效，离不开一个期望收益模型，这就是“联合假说”问题：观察到收益可预测，可能是市场无效，也可能是所用的期望收益模型错了。例如，股息率高时随后的市场平均收益较高，这可以解释为期望收益（[折现率](#glossary-discount-rate)）随经济状况变化：坏时候投资者要求更高的补偿，价格低、股息率高，随后的平均收益也高 [@cochrane2011presidential]（第 6 章）。可预测性来自风险补偿还是错误定价，是第 8 章的主题。

**业界常见含义。** 常把“能预测、能赚钱”等同于“市场无效、有 alpha”，把“市场有效”理解为“股价不可预测、赚不到钱”。

**本书用法。** 可预测性指条件期望收益 $\E_{t-1}[r_{i,t}]$ 随期初信息变化；它是否意味着市场无效，取决于这种变化能否由风险补偿解释。

**常见混淆。** 有效市场并不要求收益不可预测，只要求不存在经风险调整之后的超额收益；反过来，能赚钱也可能只是承担某种风险得到的补偿。还要区分时间序列上的可预测性（市场整体何时收益高，即[择时](#glossary-timing)）与横截面上的可预测性（哪些股票收益高，即选股），见[时序与截面](#glossary-ts-cs)。

(glossary-r2)=
### 预测好不好：样本外 R²（out-of-sample R²）

**白话。** 判断收益预测好不好，学术上常用样本外 $R^2$：预测把收益的波动解释了多少。对月度个股收益，1% 以下的 $R^2$ 就可能有意义。

**学术含义。** 样本外 $R^2_{\text{oos}} = 1 - \sum (r_{i,t} - \hat r_{i,t})^2 / \sum (r_{i,t} - \bar r_{i,t})^2$，其中 $\bar r_{i,t}$ 是某个基准预测，比较的是两者的误差平方和。市场择时文献中，基准通常是历史均值 [@campbell2008predicting]。GKX 预测个股收益时以 0 为基准，分母是 $\sum r_{i,t}^2$，不减历史均值，理由是个股历史均值的噪声很大，以它为基准会抬高 $R^2$。在这一口径下，GKX 在美国个股月度数据上，表现最好的三层神经网络 NN3 的样本外 $R^2$ 为 0.40%（NN1～NN5 为 0.33%～0.40%）[@gu2020empirical]；若改用历史均值作基准，所有方法的 $R^2$ 约高 3 个百分点（第 13、22 章）。$R^2$ 很小不等于没有经济价值：月度收益中噪声远大于可预测的部分，很小的 $R^2$ 也可以对应可观的夏普比率，Campbell 与 Thompson 在择时的语境下给出了这一换算 [@campbell2008predicting]。

**业界常见含义。** 更习惯看胜率（预测方向正确的比例）、IC 或分组收益，对“准确率”的期望也高得多。

**本书用法。** $R^2_{\text{oos}}$ 一律注明基准（0 或历史均值）、频率与对象（个股或组合、指数）。

**常见混淆。** 基准不同的 $R^2$ 不能直接比较；个股的月度 $R^2$ 与市场指数择时的 $R^2$ 也不可比。胜率高也不等于预测好：胜率不看幅度，几次大的错误可以抵消多次小的正确。

(glossary-timing)=
### 择时（timing）

**白话。** 择时是判断“现在该多买还是少买”，即根据预测调整整体仓位。

**学术含义。** 学术上的择时主要指用预测变量（如股息率、期限利差、通胀）预测市场整体的超额收益，并据以调整股票仓位。证据有争议：Welch 与 Goyal 发现，多数预测变量在样本外失效，不如历史均值 [@welch2008comprehensive]；Campbell 与 Thompson 表明，对预测值加合理的约束（如回归系数的符号与理论一致、预测的股权溢价不为负）之后，样本外有一定的预测力 [@campbell2008predicting]。样本外表现普遍不如样本内（第 6、13 章）。对风格因子的择时称为因子择时，证据同样有争议。

**业界常见含义。** 根据技术面（均线、成交量、情绪指标）或宏观信号（货币信用周期、估值、资金流向）调整股票仓位或风格配置；“择时能力”也用于评价基金经理。

**本书用法。** 择时指根据期初信息调整对市场或因子的整体暴露，对应时间序列上的可预测性（[可预测性与市场有效](#glossary-predictability)）。

**常见混淆。** 择时的样本量很小：几十年的月度数据也只有几百个观测，回测中“有效”的择时信号很容易是[过拟合](#glossary-overfitting)的结果。择时与选股的评价指标不同：择时看时间序列上的 $R^2$ 与调整仓位后的夏普比率，选股看横截面上的 IC 与多空收益。

(glossary-arbitrage)=
### 套利（arbitrage）

**白话。** 学术上的套利是“不花钱、不担风险、稳赚不赔”；业界说的套利，大多是“风险较小、基于价差的交易”。

**学术含义。** 套利指不需要初始投资、在任何状态下都不亏损、并且以正概率严格盈利的组合。无套利是资产定价的基本假设，由它可以推出存在为正的 SDF（第 2 章）。Ross（1976）的套利定价理论（APT）用的是近似套利：大量资产的分散化组合几乎消除了异质风险（第 4 章）。“套利限制”（limits to arbitrage）中的套利也取学术含义，讨论的是现实中的套利需要资本、要承担风险与成本，所以错误定价可以持续存在（第 8 章）。

**业界常见含义。** 期现套利（股指期货与现货之间的基差）、ETF 申赎套利、可转债套利、统计套利、配对交易等。这些策略都有风险：基差可能扩大，配对关系可能失效，还要承担融资与流动性风险。

**本书用法。** 套利只取学术含义；业界的这类策略，本书写出具体名称，或称为“相对价值交易”。

**常见混淆。** 统计套利是期望收益为正、但有风险的策略，不是学术意义上的套利。“这个异象被套利掉了”是学术与业界都常用的宽泛说法，指大量资金交易这一信号、使其收益下降，并非定义中的无风险套利，相关讨论见[因子拥挤与衰减](#glossary-crowding)。

(glossary-overfitting)=
### 过拟合（overfitting）

**白话。** 过拟合是模型记住了历史数据中的噪声：回测很好看，换一段数据就不灵了。

**学术含义。** 在统计学习中，过拟合指模型过于复杂，样本内误差小而样本外误差大，用正则化与交叉验证来控制（第 19 章）。在资产定价中，还有数据挖掘与多重检验的问题：许多研究者在同一批数据上尝试大量信号，即使每个都按 5% 的水平检验，也会“发现”许多偶然显著的异象；只报告显著结果的 p-hacking 会加剧这一问题。Harvey、Liu 与 Zhu 据此主张提高显著性的门槛 [@harvey2016and]（第 14 章）。

**业界常见含义。** 常指参数调得太细：均线窗口、持有期、阈值反复优化，直到回测曲线最平滑，即“回测过拟合”“曲线拟合”。

**本书用法。** 过拟合既指模型的复杂度，也指研究过程中的选择：选样本、选特征、选参数、选模型的每一次尝试都算在内（第 27 章）。

**常见混淆。** 一个回测的参数不多，不代表没有过拟合：如果得到它之前试过几十个方案，就要按“试了多少次”校正显著性（第 14 章）。样本外数据只能用一次，反复在“样本外”上修改模型，它就变成了样本内（[样本外](#glossary-oos)）。

(glossary-crowding)=
### 因子拥挤与衰减（crowding, decay）

**白话。** 一个因子被很多人知道并交易之后，收益往往变小，这是衰减；很多资金同时持有类似的头寸，这是拥挤。

**学术含义。** McLean 与 Pontiff 研究了 97 个已发表的收益预测变量，发现它们的多空收益在原文样本期之后、发表之前平均下降约 26%，他们把这一数字视为数据挖掘（统计偏误）效应的上界；发表之后平均下降约 58%，多出的约 32 个百分点归因于投资者从论文中学到并交易了这些信号 [@mclean2016does]（第 18 章）。也有研究讨论套利资本的进入与异象收益之间的关系。

**业界常见含义。** “因子拥挤”常用拥挤度指标衡量，例如多空两端的估值价差、换手率差异、因子收益波动与相关性的上升，各机构的构造不一。“因子失效”指因子在一段时间内收益为负或 IC 大幅下降。拥挤的头寸集中平仓时，可能造成多个量化产品同时大幅回撤，例如 2007 年 8 月美国股票量化基金的集体回撤。

**本书用法。** 衰减指发表或广为人知之后平均收益的下降，拥挤指持有同类头寸的资金规模；二者都与[策略容量](#glossary-size)和交易成本有关（第 18、26 章）。

**常见混淆。** 因子一段时间表现差，不一定是衰减或拥挤，也可能只是正常波动：年化夏普比率为 0.5 的因子（收益服从正态分布且各期独立），三年累计亏损的概率约为五分之一。反过来，真实的衰减在短样本中也很难与噪声区分。

(glossary-group-returns)=
## 五、收益口径

(glossary-return)=
### 收益率：简单收益与对数收益（simple return, log return）

**白话。** 收益率是一段时间内赚了百分之几，但有简单收益与对数收益两种算法，加总的方式不同。

**学术含义。** 简单收益 $R_t = (P_t + D_t)/P_{t-1} - 1$，$D_t$ 为期内分红；对数收益 $\log(1 + R_t)$。横截面上，组合收益是成分资产简单收益的加权和，$R_{p,t} = \mathbf w'\mathbf R_t$（$\mathbf w, \mathbf R_t \in \Real^N$），对数收益没有这一性质，所以构造组合时按简单收益加权。时间维度上，多期累计的对数收益等于各期对数收益之和，计算更方便。收益较小时二者接近，相差约 $R_t^2/2$。资产定价实证多用简单收益（尤其是超额收益），Campbell–Shiller 分解等推导用对数收益（第 6 章）。

**业界常见含义。** 常指产品的净值增长率。“年化收益”通常是复利口径，例如 $T$ 个月的累计净值为 $V_T/V_0$ 时，年化收益为 $(V_T/V_0)^{12/T} - 1$，而不是月均收益乘以 12。货币基金、银行理财的“七日年化收益率”等则按单利折算。

**本书用法。** 收益率默认指简单收益，用对数收益时注明；年化时注明是算术口径（月均乘以 12）还是复利口径。

**常见混淆。** 月度算术平均收益不低于月度几何平均收益，差额约为月度方差的一半；年化后，“12 × 月均简单收益”与“12 × 月均对数收益”之差约为年化方差的一半，波动越大相差越多。“月均乘以 12”与复利年化收益是两种口径，不能直接比较。例如先涨 50% 再跌 50%，两期的算术平均收益为 0，实际却亏了 25%。多只股票对数收益的平均，也不等于组合的对数收益。

(glossary-discount-factor)=
### 贴现因子（discount factor）

**白话。** “贴现因子”这个词至少有三种用法：估值中的折现系数、偏好中的耐心、定价中的随机贴现因子。前两种是确定的数，第三种是随状态变化的随机变量。

**学术含义。** 一是**主观贴现因子** $\delta$，它是偏好参数，表示投资者把明年的效用折算成今天的效用时打的折扣，$\delta$ 越小越没耐心（[第 1 章 1.1 节](#sec-ch1-two-period)）；它既不是利率，也不是资产价格。二是**随机贴现因子** $m_{t+1} = \delta u'(C_{t+1})/u'(C_t)$（[SDF](#glossary-sdf)），它把明年各状态下的一元钱折算为今天的钱，期望等于无风险债券的价格，$\E_t[m_{t+1}] = 1/R^f_t$。例如第 1 章 1.2 节的两状态例子中，$\delta = 0.99$，而 $m$ 在好状态约为 0.870、坏状态约为 1.062，期望约为 0.966，对应约 3.51% 的无风险利率。三是多期 SDF $M_{t,t+j} = m_{t+1}\cdots m_{t+j}$，为第 $t+j$ 期的支付定价。

**业界常见含义。** 估值与固定收益中的“贴现因子”“折现因子”指 $1/(1+r)^j$，即第 $j$ 年的一元钱按折现率 $r$ 折算的现值，对给定的期限是一个确定的数；“贴现率”有时也指票据贴现的利率。

**本书用法。** “主观贴现因子”专指 $\delta$；“随机贴现因子”或 SDF 专指 $m$；单说“折现率”时指期望收益（见下一条[折现率](#glossary-discount-rate)）。

**常见混淆。** 第一，把 $\delta$ 当作 $1/R^f$：只有在没有增长、没有风险时才有 $R^f = 1/\delta$。第 1 章的默认假设参数下 $\delta = 0.99$，而 $1/R^f = \E[m] \approx 0.952$，差别来自预期的消费增长与预防性储蓄（[1.4 节](#sec-ch1-lognormal)）。第二，把确定的折现系数 $1/(1+r)^j$ 与随机的 $M_{t,t+j}$ 混为一谈：前者在所有状态下相同，后者在坏状态下更大；用一个常数折现率 $r$ 时，风险调整全部折进了 $r$。

(glossary-discount-rate)=
### 折现率（discount rate）

**白话。** 学术上的折现率就是投资者要求的期望收益，而且随时间变化；业界做估值时的折现率，通常是一个固定的数。

**学术含义。** 资产的折现率指它的期望收益：价格等于未来现金流按期望收益折现的现值。Cochrane 在会长演讲中强调，市场整体的价格—红利比等估值比率的变动，主要对应折现率的变化，而不是未来现金流预期的变化；折现率随时间、也随资产变化 [@cochrane2011presidential]（第 6 章）。与 [SDF](#glossary-sdf) 的区别是：SDF 对所有资产相同，折现率因资产而异，由资产收益与 SDF 的协方差决定。

**业界常见含义。** 现金流折现（DCF）估值中常用加权平均资本成本（WACC）作为折现率，其中的股权成本多用 CAPM 估计，通常取一个常数。卖方策略中说的“分母端”“无风险利率下行利好估值”，也是折现率的思路。

**本书用法。** 折现率指期望收益，一般随时间变化，即条件期望收益 $\E_t[R_{i,t+1}]$；对数形式在第 6 章另行定义。第 1 章红利增长独立同分布的模型中，折现率是常数 $\E[R]$，价格—红利比化为 Gordon 增长模型 $G/(\E[R] - G)$，价格有限要求折现率高于红利的期望增长 $G$（[1.5 节](#sec-ch1-lucas)）。折现率与贴现因子的区别见[贴现因子](#glossary-discount-factor)。

**常见混淆。** 用常数折现率做 DCF，等于假定期望收益不变。估值低既可能意味着便宜（错误定价），也可能意味着投资者要求更高的补偿（风险更高），这与[可预测性与市场有效](#glossary-predictability)讨论的是同一个问题。

(glossary-ts-cs)=
### 时序与截面（time series, cross section）

**白话。** 时序看一个对象随时间的变化，截面看同一时点不同对象之间的差别。

**学术含义。** 至少有三层含义。一是两种回归：时间序列回归对每只资产沿时间回归，得到载荷与截距（第 9 章）；横截面回归每期沿资产回归，得到风险溢价或特征的补偿（[横截面回归与 Fama–MacBeth](#glossary-fm)，第 10 章）。二是两种可预测性：预测市场整体何时收益高（时序，[择时](#glossary-timing)），与预测哪些资产收益高（截面，选股）。三是两种策略：时序动量（time-series momentum）按每个资产自己过去的收益决定多空 [@moskowitz2012time]，它本身就是一个学术上的策略概念；截面动量按资产之间的相对收益排序（[动量](#glossary-momentum)）。

**业界常见含义。** “时序策略”常指 CTA 趋势跟踪等按单个品种自身走势决定方向的策略，对应学术上的时序动量；“截面策略”指选股或品种间相对排序的策略，例如多因子选股、商品期货的截面多空，对应学术上的截面动量等排序策略。

**本书用法。** 时序与截面按上面三层含义使用，并写明指的是回归、可预测性还是策略。

**常见混淆。** 同一个信号可以有时序与截面两种用法，结论可能不同：一个特征在横截面上能区分股票的收益，不等于它在时间上能预测市场整体的收益，反之亦然。时序动量与截面动量相关但不相同：所有资产同时上涨时，截面动量仍有空头，时序动量则全部做多。

| **二、绩效与风险指标** | | |
| [夏普比率](#glossary-sharpe) | 超额收益均值 ÷ 标准差；月度年化乘以 $\sqrt{12}$ | 净值收益年化计算；有时不减无风险利率 |
| [信息比率](#glossary-ir) | 评估比率 $a_i/\sigma(\varepsilon_i)$；残差收益 ÷ 残差风险 | 超额收益 ÷ 跟踪误差 |
| [风险](#glossary-risk) | 与 SDF 的协方差；只有系统性风险得到补偿 | 波动、回撤、亏损可能与各类暴露 |
| [回撤](#glossary-drawdown) | 资产定价文献很少使用；对冲基金与 CTA 评价中较常见 | 核心指标；最大回撤与回撤恢复期 |
| [显著性](#glossary-significance) | 统计显著（$t$ 值）；另看经济显著 | 效果明显、回测好看 |
| [IC、Rank IC、ICIR](#glossary-ic) | 对应横截面回归斜率（精确）及其 $t$ 值（近似） | 信号与下期收益的横截面相关系数及其稳定性 |
| **三、风格与特征名称** | | |
| [价值与成长](#glossary-value-growth) | 按 B/M 或 EP 排序的高低两组 | 低估值、高股息；营收与利润增速高 |
| [价格—红利比、市盈率与股息率](#glossary-pd) | $P/D$ 与股息率 $D/P$；估值比率与收益可预测性 | 市盈率 $P/E$ 最常用；红利策略看股息率 |
| [动量](#glossary-momentum) | 截面动量（12-1）；时序动量 | 价格趋势与强势股；CTA 趋势跟踪 |
| [流动性](#glossary-liquidity) | 个股交易便利程度；流动性风险的载荷 | 资金面与宏观流动性 |
| [换手率](#glossary-turnover) | 个股成交量 ÷ 流通股本 | 个股换手率因子；组合换手率 |
| [规模](#glossary-size) | 市值 | 大小盘风格；资产管理规模与策略容量 |
| [质量](#glossary-quality) | 盈利能力（资产毛利率、RMW） | ROE、负债、现金流等的综合打分 |
| [风格](#glossary-style) | 对特征或因子的倾斜；Sharpe 风格分析 | 大小盘与成长价值切换；Barra 风格因子 |
| **四、模型与方法** | | |
| [因子模型](#glossary-factor-model) | 定价模型、统计因子模型、风险模型 | 多因子选股模型；风险模型 |
| [消费 CAPM](#glossary-ccapm) | 以消费增长为因子的 β 模型，$\lambda_c = \gamma\sigma_c^2$ | 很少使用；宏观因子与“消费复苏”一类的判断 |
| [风险模型](#glossary-risk-model) | 协方差矩阵的因子结构 | Barra 类模型；风险预测与归因 |
| [横截面回归与 Fama–MacBeth](#glossary-fm) | 每期沿股票回归；系数的时间平均及其时间序列标准误 | Barra 因子收益；单因子测试的回归法 |
| [中性化](#glossary-neutralization) | 控制变量回归；双重排序 | 对行业、市值回归取残差 |
| [多空组合、对冲](#glossary-long-short) | 假定可以卖空的零成本组合 | 股指期货对冲的市场中性；只做多的指数增强 |
| [样本外](#glossary-oos) | 按时间顺序、估计时未用过的数据 | 回测之后的区间；模拟盘与实盘 |
| [可预测性与市场有效](#glossary-predictability) | 可预测不等于无效；时变的风险补偿 | 能预测、能赚钱即市场无效 |
| [样本外 R²](#glossary-r2) | 注明基准（0 或历史均值）；个股月度 1% 以下即可能有意义 | 胜率、IC 与分组收益 |
| [择时](#glossary-timing) | 预测市场超额收益；样本外证据有争议 | 技术面或宏观信号的仓位调整 |
| [套利](#glossary-arbitrage) | 零投资、无亏损、以正概率严格获利 | 期现套利、统计套利、配对交易等有风险的交易 |
| [过拟合](#glossary-overfitting) | 样本外误差大；数据挖掘与多重检验 | 参数调得太细 |
| [因子拥挤与衰减](#glossary-crowding) | 发表之后收益下降 | 拥挤度指标；因子失效 |
| **五、收益口径** | | |
| [收益率](#glossary-return) | 简单收益与对数收益 | 净值增长率；复利年化 |
| [贴现因子](#glossary-discount-factor) | 主观贴现因子 $\delta$；随机贴现因子 $m$ | 确定的折现系数 $1/(1+r)^j$ |
| [折现率](#glossary-discount-rate) | 期望收益，随时间变化 | DCF 中的 WACC，通常为常数 |
| [时序与截面](#glossary-ts-cs) | 两种回归、两种可预测性、时序与截面动量 | CTA 趋势跟踪与选股 |

# 前言

## 本书写给谁

本书写给这样一类读者：已经进入资产定价方向的研究，读过不少论文，也能熟练写代码处理数据，但感到自己的理论与计量基础不够系统——知道 Fama–MacBeth 回归怎么跑，却说不清它的标准误为什么要做 Shanken 修正；知道随机贴现因子（stochastic discount factor，SDF）是什么，却很难从一个具体的模型出发把定价方程推导到可以检验的矩条件。读者的目标是做机器学习资产定价的学术研究，研究对象是中国股票市场。

本书假定读者熟悉线性代数、概率论与数理统计的基本内容，熟悉 Python 与 numpy、pandas；不假定读者系统学过资产定价理论或金融计量。代码只在涉及建模选择时解释，经济含义、数学推导与论证步骤则尽量写完整。

## 本书的定位

本书力求自包含：不借助其他教材，应当能从头读到尾。经典教材，例如 Cochrane 的《Asset Pricing》[@cochrane2005asset]，以及各章引用的原始论文，是本书的出处与延伸阅读，而不是前置要求。本书的推导由作者重新组织，不转写原书文字；每一处关键结论都会注明它最早或最常被引用的出处。

写作中难免出错。读者引用本书内容写论文时，应当回到原始文献核对。正文中凡是标注“待核实”的地方，表示作者对其中的出处、年份或数字没有把握，暂时不应当作确定的结论使用；这些标记会在后续修订中逐一核对并消除。

## 全书结构

全书分为准备部分与四个主体部分：

| 部分 | 解决的问题 | 依赖 |
|---|---|---|
| 第零部分　准备 | 如何使用本书、全书记号、模拟市场生成器；附录 A 汇总数学工具 | 无 |
| 第一部分　资产定价理论 | 价格从哪里来：消费与欧拉方程、SDF、无套利、均值—方差前沿、β 定价、条件模型、可预测性、资产定价之谜、行为金融 | 第零部分 |
| 第二部分　实证计量 | 如何检验定价模型：时间序列检验、横截面回归、GMM、标准误、预测检验、多重检验 | 第一部分 |
| 第三部分　横截面实证 | 如何构造与评价因子和异象，以及中国市场的制度特征 | 第一、二部分 |
| 第四部分　机器学习资产定价 | 如何用高维与非线性方法预测收益、估计因子与 SDF，并检验其经济含义与可实施性 | 第一～三部分 |

第一部分与第二部分是全书的地基。只关心机器学习方法的读者也不宜跳过它们：第四部分的大多数方法，本质上是在第一部分的定价方程与第二部分的估计框架上换了一个函数类。

## 每章的结构

除前言与附录外，每章按同一个模板组织：

1. **学习目标**：读完本章应当会做什么。
2. **动机**：本章在研究中解决什么问题。
3. **正文**：按“定义—直觉—定理—逐步证明—代码验证”的顺序展开。符号推导用 `sympy` 验证，统计性质用蒙特卡洛模拟验证。
4. **A 股视角**：本章内容放到中国市场时需要注意什么。
5. **模拟实验**：用模拟市场检验方法能否恢复已知的真值。
6. **常见误区**：初学者和有经验的研究者都容易犯的错误。
7. **本章小结**
8. **习题**：分为三级。**概念题**检查对定义与经济含义的理解，通常不需要计算；**推导题**要求写出完整的证明或推导；**编程题**要求用模拟数据实现并检验一个结论。答案默认折叠，建议先独立完成再展开。
9. **文献与延伸阅读**

## 为什么全书用模拟数据

本书所有数值例子都使用模拟数据，由本项目自带的生成器 `apsim` 产生。原因有两点。

第一，模拟数据的真值已知。用真实数据估计一个因子模型，得到的数字无从判断对错；用模拟数据，真实的 SDF、因子载荷与定价误差都由我们设定，于是可以直接检验一个估计方法能否恢复真值、在多大样本下恢复、在什么条件下失败。这是检查推导与代码最便宜、也最可靠的办法。

第二，模拟数据可以完全复现。全书每一个随机过程都通过显式的随机种子（seed）控制，任何读者在任何机器上重新构建本书，都会得到相同的数字与图形。

模拟数据的代价是：它只包含我们放进去的结构。真实市场中的涨跌停、停牌、卖空限制、财报披露滞后等特征，在模拟器中要么被省略，要么要在后续章节专门加入。**正式研究必须换用 CSMAR、Wind 等数据库的时点（point-in-time）数据**，并严格保证每个变量在使用时点确实可得。本书的模拟结果只用来理解方法，不能当作关于中国市场的经验结论。

## 如何构建与阅读

本书的源文件是 MyST Markdown，在构建时执行全部代码。在项目根目录下：

```bash
uv sync                       # 安装依赖
sh scripts/build.sh --clean   # 冷构建全书：清除执行缓存，执行全部代码
sh scripts/serve.sh           # 启动本地服务器，浏览器打开 http://localhost:8000
uv run pytest                 # 运行 apsim 的单元测试
```

构建以严格模式进行：任何代码单元报错，包括正文数字所依赖的 `assert` 不成立，构建都会失败。所以网页上看到的每一个数字，要么由代码当场算出并经过核对，要么是不依赖随机种子的说法。

写作或修改时可以用实时预览：`cd book && uv run jupyter book start --execute`。构建所需的环境与常见问题见[第 0 章](./part0/ch00-guide.md)。

建议的阅读顺序是：先读第 0 章与[记号表](./notation.md)，再按顺序读第一、二部分；第三、四部分可以按研究需要选读，遇到前文的记号或结论时回查。

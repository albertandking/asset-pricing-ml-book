# 《资产定价与机器学习：从理论到 A 股实证》设计文档

- 日期：2026-10-26
- 状态：已获用户确认（结构、目录、模板与写作原则）

## 1. 目标与定位

- **读者**：中国高校金融学博士（资产定价方向），工程能力强（AKShare、AKQuant 作者），资产定价理论与实证计量基础需要系统补强，目标是做学术方向的 ML 资产定价研究（中国市场）。
- **定位**：自包含教材。不依赖原书即可学完；原始文献作为出处与延伸阅读。
- **形式**：本地网页阅读的电子书，正文含公式、定理与证明、可执行代码、习题与折叠答案。
- **数据**：全部使用模拟数据，由本项目自带的“模拟 A 股市场”生成器产生；正文中注明正式研究须换用 CSMAR/Wind 等时点数据。
- **节奏**：逐章写作。每章完成后由用户阅读反馈，再写下一章。

## 5. 模拟市场生成器 `apsim`

**作用**：为全书提供已知真值的数据，使每种方法都能检验“能否恢复真值”，并保证各章数据前后一致。

**原则**：按章节需要逐步扩展（第 0 章只实现最小可用版本），每个公开函数有单元测试；所有随机过程通过显式的 `seed` 或 `numpy.random.Generator` 控制。

**计划中的模块**（随章节逐步实现）：

| 模块 | 内容 | 首次使用 |
|---|---|---|
| `apsim.market` | 横截面面板：N 只股票、T 期；因子收益；由特征决定的因子载荷（IPCA 式 β = zΓ）；可选的特征驱动定价误差（错误定价 α）；可选非线性与交互项（供第四部分）；返回包含全部真实参数的数据类 | 第 0 章 |
| `apsim.consumption` | 消费型模型：对数正态消费增长、习惯形成等，用于生成 SDF 与资产价格 | 第 1 章 |
| `apsim.timeseries` | 时间序列可预测性：AR(1) 预测变量（如股息率）与时变风险溢价 | 第 6 章 |
| `apsim.frictions` | A 股摩擦：涨跌停、停牌、T+1、卖空限制、ST、上市不满一年、小市值壳股 | 第 15 章 |
| `apsim.stats` | 第 0 章：最小二乘与同方差标准误、交互项设计矩阵、Fama–MacBeth；第 9 章起：GRS、Shanken 修正、Newey–West、GMM、样本外 R²、DM、CW、多重检验 | 第 0 章 |
| `apsim.portfolio` | 组合排序、市值/等权加权、因子构造（含 CH3） | 第 15 章 |
| `apsim.plotting` | 统一的作图风格（中文字体） | 第 0 章 |

数据频率先实现月度；需要涨跌停等日内或日度机制时（第 15、17、26 章）再加日度。

## 7. 写作原则

1. **推导可验证**：关键推导配代码验证，符号推导用 `sympy`，统计性质用蒙特卡洛模拟。
2. **统一记号**：第 0 章确定记号表 `notation.md`，全书遵守。
3. **引用规范**：参考文献统一放在 `references.bib`；没有把握的出处、年份、数字在正文中标注“待核实”，不写成确定的结论。
4. **自写内容**：不转写教材原文，用自己的语言讲解与重新推导，注明出处。
5. **篇幅**：每章约 8000～15000 字。
6. **排版**：
   - 中文全角标点，遵循 GB/T 15834-2011；数值范围用“～”，引号用“”
   - 屏幕阅读字体：中文微软雅黑，英文和数字 Arial，代码 Consolas（通过 `custom.css` 设置，并给出 macOS 下的回退字体）
7. **可复现**：所有随机过程固定种子。
8. **依赖种子的数字**：正文引用代码输出中的具体数值时，二者必须择一：要么由代码单元中的 `assert` 守护（例如断言该数值落在正文所述的区间内，使种子或模拟器变化时构建失败），要么改为不依赖种子的说法（“见上方输出”“约 2 倍标准误”“量级很小”）。不得把某次运行的数字直接写进正文而不加守护。
9. **矩阵运算的讲解**：
   - (a) 正文中的每个矩阵公式，紧随其后或在式中标注各项的维度，使读者能核对乘法是否相容；
   - (b) 做矩阵代数的代码单元，在关键行加简短的形状注释（如 `# (N, L+1) @ (L+1, K) -> (N, K)`），正文说明该行实现的是哪个公式；
   - (c) `einsum`、广播、`reshape` 与 Kronecker 积／vec 技巧在一章中首次出现时，用一两句白话解释，并写出等价的公式；
     用到 Kronecker 积／vec 时还须：写出恒等式 vec(ABC)=(C′⊗A)vec(B)，并标明 A、B、C 各自取什么、各项的维度；说明数学上的 vec 按列（列优先）叠放，而 NumPy 的 `ravel`／`reshape` 默认按行（行优先，C 顺序）展开，所以 `M.ravel()` 是 vec(M′)、`M.ravel(order="F")` 才是 vec(M)；写明设计矩阵的 `reshape` 怎样对应 Kronecker 积的行（例如 `(a[:, :, None] * b[:, None, :]).reshape(n, -1)` 的每一行是 (a ⊗ b)′，后一维变化最快），以及系数向量怎样用 `reshape` 还原为矩阵；并在代码单元中用 `np.kron` 与 `assert` 核对这一对应，同时断言按另一种顺序展开时结果不相等；
   - (d) 用 `np.linalg.solve`／`lstsq` 而不是 `inv`，原因在记号表中说明一次。
10. **字体区分标量、向量与矩阵**：标量用斜体不加粗；向量用小写粗体（拉丁字母 `\mathbf`，希腊字母 `\boldsymbol`，源文件中用宏 `\bv`），一律为列向量；矩阵用大写粗体。支付 $x_{t+1}$、价格 $P_t$、SDF $m_{t+1}$ 为标量。详见 `book/notation.md` 的“向量与矩阵约定”。
11. **概念先白话、后例子、再公式**：专业概念首次出现时，先用一两句白话说明，再给具体数值例子，最后给公式；全书遵守。
12. **术语对照**：每章写完后，把本章新出现的、学术与业界含义不同的术语补入 `book/glossary.md`（《术语对照：学术与业界》），按“学术含义—业界常见含义—本书用法—常见混淆”的格式撰写，并更新页末总表。
13. **符号读法**：每章出现新的希腊字母、修饰符号或运算符时，补充到 `book/notation.md` 的“符号读法”一节（读法与本书含义）。
14. **长章拆页**：每章源文件若超过约 3 万字符，按节拆成子页面，在 `myst.yml` 中作为该章首页的 `children`。mystmd 中每个页面使用独立的内核，所以每页开头加一个“本页准备”代码单元，只导入并重建本页需要的对象，参数与种子与原处完全相同；各页的 frontmatter 都写 `numbering.enumerator`，公式编号跨页接续时用 `numbering.equation.continue: true`，保证整章编号唯一。

## 8. 完成标准

一章视为完成，需同时满足：

1. `jupyter book build --html --execute` 全书构建成功，该章代码全部执行无报错；验收必须用 `sh scripts/build.sh --clean` 冷构建（删除执行缓存后以 `--strict` 构建，代码单元中的 assert 失败或任何警告都会使构建失败）；
2. `apsim` 新增或修改的函数通过 `pytest`；
3. 本章各项“代码验证”的结果与推导结论一致；
4. 用户阅读后确认，或提出的修改已完成。

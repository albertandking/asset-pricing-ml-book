## 5. 模拟市场生成器 `apsim`

**作用**：为全书提供已知真值的数据，使每种方法都能检验“能否恢复真值”，并保证各章数据前后一致。

**原则**：按章节需要逐步扩展（第 0 章只实现最小可用版本），每个公开函数有单元测试；所有随机过程通过显式的 `seed` 或 `numpy.random.Generator` 控制。

**计划中的模块**（随章节逐步实现）：

| 模块 | 内容 | 首次使用 |
|---|---|---|
| `apsim.market` | 横截面面板：N 只股票、T 期；因子收益；由特征决定的因子载荷（IPCA 式 β = zΓ）；可选的特征驱动定价误差（错误定价 α）；可选非线性与交互项（供第四部分）；返回包含全部真实参数的数据类 | 第 0 章 |
| `apsim.consumption` | 消费型模型：对数正态消费增长、习惯形成等，用于生成 SDF 与资产价格 | 第 1 章 |
| `apsim.timeseries` | 时间序列可预测性：AR(1) 预测变量（如股息率）与时变风险溢价 | 第 6 章 |
| `apsim.frictions` | A 股摩擦：涨跌停、停牌、T+1、卖空限制、ST、上市不满一年、小市值壳股 | 第 15 章 |
| `apsim.stats` | GRS、Fama–MacBeth、Shanken 修正、Newey–West、GMM、样本外 R²、DM、CW、多重检验 | 第 9 章起 |
| `apsim.portfolio` | 组合排序、市值/等权加权、因子构造（含 CH3） | 第 15 章 |
| `apsim.plotting` | 统一的作图风格（中文字体） | 第 0 章 |

数据频率先实现月度；需要涨跌停等日内或日度机制时（第 15、17、26 章）再加日度。

## 7. 写作原则

1. **推导可验证**：关键推导配代码验证，符号推导用 `sympy`，统计性质用蒙特卡洛模拟。
2. **统一记号**：第 0 章确定记号表 `notation.md`，全书遵守。
3. **引用规范**：参考文献统一放在 `references.bib`；没有把握的出处、年份、数字在正文中标注“待核实”，不写成确定的结论。
4. **自写内容**：不转写教材原文，用自己的语言讲解与重新推导，注明出处。
5. **篇幅**：每章约 8000～15000 字。
6. **排版**：
   - 中文全角标点，遵循 GB/T 15834-2011；数值范围用“～”，引号用“”
   - 屏幕阅读字体：中文微软雅黑，英文和数字 Arial，代码 Consolas（通过 `custom.css` 设置，并给出 macOS 下的回退字体）
7. **可复现**：所有随机过程固定种子。

## 8. 完成标准

一章视为完成，需同时满足：

1. `jupyter book build --html --execute` 全书构建成功，该章代码全部执行无报错；

3. 本章各项“代码验证”的结果与推导结论一致；
4. 用户阅读后确认，或提出的修改已完成。
